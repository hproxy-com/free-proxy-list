## प्रत्येक ओळ तुम्हाला काय सांगते

बहुतेक मोफत प्रॉक्सी याद्या तुम्हाला फक्त एक उघडा `ip:port` देतात. इथे प्रत्येक ओळीत ती मोजमापेही आहेत जी ठरवतात की प्रॉक्सी एका विनंतीच्या लायक आहे की नाही:

| फील्ड | अर्थ |
|-------|-------------------|
| `protocols` | HTTP, HTTPS, SOCKS4 आणि SOCKS5 पैकी ज्यांवर तिने खरोखर प्रतिसाद दिला ते प्रोटोकॉल |
| `anonymity` | पारदर्शक, निनावी किंवा elite: लक्ष्य तुमचा खरा IP पाहू शकते का |
| `country` / `city` | बाहेर पडण्याचे ठिकाण कुठे आहे |
| `latency_ms` | शेवटच्या तपासणीत मोजलेला प्रतिसाद वेळ |
| `uptime_24h` / `uptime_7d` | तिने किती वेळा प्रतिसाद दिला, जेणेकरून एकदा चालू असलेली प्रॉक्सी सतत चालू राहणाऱ्या प्रॉक्सीसारखी दिसू नये |

हे सर्व [all.json](../all.json) आणि [all.csv](../all.csv) मध्ये आहे, आणि [hproxy.com वरील थेट यादीत](https://hproxy.com/free-proxy-list) सुद्धा, जिथे प्रत्येक ओळ देश, प्रोटोकॉल, निनावीपणा आणि अपटाइमनुसार गाळता येते.

## AI सहाय्यकातून वापरा

हीच यादी AI सहाय्यक आणि एजंटांसाठीही खुली आहे. HProxy त्याच की-विरहित API वर तीन साधनांसह MCP सर्व्हर चालवते, `proxy_list`, `proxy_check` आणि `ip_lookup`, आणि Claude Code, Claude Desktop, Cursor आणि Windsurf साठी सेटअप [hproxy.com/tools/ai](https://hproxy.com/tools/ai) वर आहे. API चे दस्तऐवज [hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list) वर आहेत, आणि संपूर्ण मोफत API सहाय्यकांसाठी लिहिलेल्या एका markdown पानात मावते: [hproxy.com/llms/free-proxy.txt](https://hproxy.com/llms/free-proxy.txt).

सहाय्यकासाठी संपूर्ण सूचना: प्रत्येक चालू प्रॉक्सीसाठी `https://hproxy.com/api/proxy-list?format=json` आणा, आणि गाळण्यासाठी `protocol=socks5`, `country=US`, `anonymity=elite` किंवा `min_uptime_pct=90` जोडा. की नाही, साइनअप नाही, CORS खुले. कोणतीही प्रॉक्सी `https://hproxy.com/api/proxy-check?proxy=ip:port` ने तपासा. या सार्वजनिक मोफत प्रॉक्सी आहेत: कोणत्याही क्षणी निम्म्याहून कमी प्रतिसाद देतील अशी अपेक्षा ठेवा, लहान टाइमआउट ठेवा आणि पुढच्याकडे जा.

तुम्ही ही यादी तुमच्या स्वतःच्या सॉफ्टवेअरमध्ये मोफत आणि न विचारता समाविष्ट करू शकता. काही चालले नाही तर, [hproxy.com/contact](https://hproxy.com/contact) वर मदत चोवीस तास उपलब्ध आहे.

## आकडे मोफत प्रॉक्सींबद्दल काय सांगतात

इंजिन आतापर्यंत पाहिलेल्या प्रत्येक प्रॉक्सीचा इतिहास ठेवते, त्यामुळे मोफत प्रॉक्सींबद्दलचे नेहमीचे दावे अंदाज बांधण्याऐवजी मोजता येतात. 2026-09-05 रोजी पूलवर केवळ-वाचन क्वेरी: 763,409 प्रॉक्सी आणि 115,078,758 पडताळणी तपासण्या.

- **एक मोफत प्रॉक्सी सुमारे सहा दिवस जगते.** मृत झालेल्या 691,179 प्रॉक्सींमधील आयुष्याचा मध्यक: 144.5 तास. 22.6 टक्के पहिल्याच तासात मृत झाल्या, आणि 17 टक्के महिन्याहून अधिक टिकल्या.
- **चालू प्रॉक्सी तिच्या निम्म्याहून कमी तपासण्यांना प्रतिसाद देते.** चालू संचातील एक प्रॉक्सी तिच्या स्वतःच्या पडताळणी तपासण्यांपैकी 45.5 टक्क्यांमध्ये उत्तीर्ण झाली. आतापर्यंत ट्रॅक केलेल्या 765,494 प्रॉक्सींपैकी (2026-09-06) 667 ने त्यांच्या 90 टक्के किंवा अधिक तपासण्यांना प्रतिसाद दिला; त्या [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) वर सूचीबद्ध आहेत.
- **इंटरनेटवरील मोफत याद्या एकच पूल आहेत.** सरासरी चालू प्रॉक्सी आम्ही गोळा करत असलेल्या स्रोतांपैकी 17.9 वर दिसते, आणि 94.7 टक्के एकाहून अधिक स्रोतांवर दिसतात. अनेक याद्यांमधून कॉपी केल्यास तुम्हाला त्याच प्रॉक्सी वेगवेगळ्या तारखांसह मिळतात.

व्यवहारात: मोफत प्रॉक्सी सार्वजनिक पाने, चाचण्या आणि स्थान तपासणीसाठी वापरा, लहान टाइमआउट आणि पुढच्या ओळीवर पुन्हा प्रयत्न ठेवून. ज्यात लॉगिन, पेमेंट किंवा बॉट ओळखणारे लक्ष्य आहे अशा कोणत्याही कामाला सतत चालू राहणारी आणि संपूर्ण इंटरनेटसोबत शेअर न केलेली प्रॉक्सी लागते; पाहा [जेव्हा मोफत प्रॉक्सी पुरेशी नसते](#जेवहा-मोफत-परॉकसी-पुरेशी-नसते).

## नेहमी विचारले जाणारे प्रश्न

**या यादीत किती मोफत प्रॉक्सी आहेत?**
आतापर्यंत 773,101 ट्रॅक केल्या आहेत. 6,675 या मिनिटाला चालू आहेत आणि 34,218 ने गेल्या 48 तासांत प्रतिसाद दिला, आणि प्रकाशित फाइलींमध्ये नेमक्या त्याच आहेत.

**कोणते प्रोटोकॉल समर्थित आहेत?**
HTTP, HTTPS, SOCKS4 आणि SOCKS5. प्रत्येक प्रॉक्सीवर तेच प्रोटोकॉल लेबल आहेत ज्यांवर तिने खरोखर प्रतिसाद दिला, ज्यांखाली ती सूचीबद्ध होती ते नव्हे.

**यादी किती वेळा अद्ययावत होते?**
उमेदवार दर काही मिनिटांनी स्रोतांमधून गोळा केले जातात आणि चोवीस तास पुन्हा तपासले जातात. ही रेपॉझिटरी दिवसातून अनेकदा ताजी होते, आणि [hproxy.com वरील थेट यादी](https://hproxy.com/free-proxy-list) काही मिनिटांत निकाल दाखवते.

**प्रॉक्सी निनावी आहेत का?**
लक्ष्य तुमचा खरा IP पाहते की नाही यावरून प्रत्येकीला पारदर्शक, निनावी किंवा elite असा दर्जा दिला जातो. `all.json` किंवा `all.csv` मधील `anonymity` फील्डवर गाळा, किंवा `elite.txt` घ्या.

**Python मध्ये प्रॉक्सी कशी वापरू?**
वर [तुमच्या कोडमध्ये वापरा](#तुमचया-कोडमधये-वापरा) पाहा. `all.txt` आणा, एक ओळ निवडा, आणि ती `requests` ला `http` आणि `https` प्रॉक्सी म्हणून द्या. टाइमआउट ठेवा आणि अपयश आल्यास पुढच्या ओळीवर जा, कारण मोफत प्रॉक्सी तिच्या निम्म्याहून कमी तपासण्यांना प्रतिसाद देते.

**मला API की किंवा खाते लागते का?**
नाही. इथल्या कच्च्या फाइलींना किंवा [hproxy.com वरील मोफत API](https://hproxy.com/docs/free-proxy-list) ला साइनअप किंवा की लागत नाही.

**AI सहाय्यक किंवा एजंट ही यादी वापरू शकतो का?**
हो. MCP सर्व्हर, की-विरहित API आणि llms.txt पाने त्यासाठीच बनवली आहेत; पाहा [AI सहाय्यकातून वापरा](#ai-सहाययकातून-वापरा).

**मोफत प्रॉक्सी वापरणे सुरक्षित आहे का?**
त्यांना सार्वजनिक आणि अविश्वसनीय समजा. सार्वजनिक पाने स्क्रॅप करण्यासाठी, चाचण्यांसाठी आणि स्थान तपासणीसाठी त्या ठीक आहेत. सार्वजनिक प्रॉक्सीमार्फत कधीही पासवर्ड, सेशन किंवा पेमेंट डेटा पाठवू नका: ती चालवणारा एंड-टू-एंड एन्क्रिप्ट न केलेले सर्व काही वाचू शकतो.

**ही यादी इतर मोफत प्रॉक्सी याद्यांपेक्षा कशी वेगळी आहे?**
इथली प्रत्येक प्रॉक्सी चोवीस तास पुन्हा तपासली जाते आणि तिची मोजमापे सोबत ठेवते, आणि यादी इतर याद्या वापरतात त्याच सार्वजनिक स्रोतांमधून बनवली आहे, त्यामुळे एक फाइल संपूर्ण संग्रहाची जागा घेते. तिच्यामागचा इतिहासही प्रकाशित आहे, पाहा [आकडे मोफत प्रॉक्सींबद्दल काय सांगतात](#आकडे-मोफत-परॉकसींबददल-काय-सांगतात).
