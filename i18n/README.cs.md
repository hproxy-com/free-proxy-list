## Co říká každý řádek

Většina seznamů bezplatných proxy vám dá holé `ip:port`. Tady každý řádek nese i měření, která rozhodují, zda proxy stojí za požadavek:

| Pole | Co znamená |
|-------|-------------------|
| `protocols` | Protokoly, na kterých skutečně odpověděla, z HTTP, HTTPS, SOCKS4 a SOCKS5 |
| `anonymity` | Transparentní, anonymní nebo elite: zda cíl vidí vaši skutečnou IP |
| `country` / `city` | Kde se nachází výstup |
| `latency_ms` | Změřená doba odezvy při poslední kontrole |
| `uptime_24h` / `uptime_7d` | Jak často odpovídala, aby proxy, která běžela jednou, nevypadala jako ta, která běží stále |

To vše je v [all.json](../all.json) a [all.csv](../all.csv) a v [živém seznamu na hproxy.com](https://hproxy.com/free-proxy-list), kde lze každý řádek filtrovat podle země, protokolu, anonymity a dostupnosti.
