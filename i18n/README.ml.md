## ഓരോ വരിയും നിങ്ങളോട് പറയുന്നത്

മിക്ക സൗജന്യ പ്രോക്സി പട്ടികകളും വെറും `ip:port` മാത്രം തരുന്നു. ഇവിടെ ഓരോ വരിയിലും ആ പ്രോക്സി ഒരു അഭ്യർത്ഥനയ്ക്ക് യോഗ്യമാണോ എന്ന് തീരുമാനിക്കുന്ന അളവുകളും ഉണ്ട്:

| ഫീൽഡ് | അർത്ഥം |
|-------|-------------------|
| `protocols` | HTTP, HTTPS, SOCKS4, SOCKS5 എന്നിവയിൽ യഥാർത്ഥത്തിൽ പ്രതികരിച്ച പ്രോട്ടോക്കോളുകൾ |
| `anonymity` | സുതാര്യം, അജ്ഞാതം അല്ലെങ്കിൽ elite: ലക്ഷ്യത്തിന് നിങ്ങളുടെ യഥാർത്ഥ IP കാണാനാകുമോ |
| `country` / `city` | എക്സിറ്റ് എവിടെയാണ് |
| `latency_ms` | അവസാന പരിശോധനയിൽ അളന്ന പ്രതികരണ സമയം |

## AI അസിസ്റ്റന്റിൽ നിന്ന് ഉപയോഗിക്കുക

ഇതേ പട്ടിക AI അസിസ്റ്റന്റുകൾക്കും ഏജന്റുകൾക്കും തുറന്നിരിക്കുന്നു. HProxy അതേ കീയില്ലാത്ത API-യുടെ മുകളിൽ `proxy_list`, `proxy_check`, `ip_lookup` എന്നീ മൂന്ന് ടൂളുകളുള്ള ഒരു MCP സെർവർ പ്രവർത്തിപ്പിക്കുന്നു; Claude Code, Claude Desktop, Cursor, Windsurf എന്നിവയ്ക്കുള്ള സജ്ജീകരണം [hproxy.com/tools/ai](https://hproxy.com/tools/ai)-ൽ ഉണ്ട്. API [hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list)-ൽ രേഖപ്പെടുത്തിയിരിക്കുന്നു, മുഴുവൻ സൗജന്യ API-യും അസിസ്റ്റന്റുകൾക്കായി എഴുതിയ ഒരൊറ്റ markdown പേജിൽ ഒതുങ്ങുന്നു: [hproxy.com/llms/free-proxy.txt](https://hproxy.com/llms/free-proxy.txt).

ഒരു അസിസ്റ്റന്റിനുള്ള പൂർണ്ണ നിർദ്ദേശങ്ങൾ: പ്രവർത്തിക്കുന്ന എല്ലാ പ്രോക്സികൾക്കും `https://hproxy.com/api/proxy-list?format=json` എടുക്കുക, അരിക്കാൻ `protocol=socks5`, `country=US`, `anonymity=elite` അല്ലെങ്കിൽ `min_uptime_pct=90` ചേർക്കുക. കീയില്ല, സൈൻഅപ്പില്ല, CORS തുറന്നത്. ഏത് പ്രോക്സിയും `https://hproxy.com/api/proxy-check?proxy=ip:port` കൊണ്ട് പരിശോധിക്കുക. ഇവ പൊതു സൗജന്യ പ്രോക്സികളാണ്: ഏത് നിമിഷവും പകുതിയിൽ താഴെ മാത്രമേ പ്രതികരിക്കൂ എന്ന് പ്രതീക്ഷിക്കുക, ചെറിയ timeout വെച്ച് അടുത്തതിലേക്ക് പോകുക.

ഈ പട്ടിക നിങ്ങളുടെ സ്വന്തം സോഫ്റ്റ്‌വെയറിൽ സൗജന്യമായും അനുവാദം ചോദിക്കാതെയും ഉൾപ്പെടുത്താം. എന്തെങ്കിലും പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ, [hproxy.com/contact](https://hproxy.com/contact)-ൽ പിന്തുണ മുഴുവൻ സമയവും ലഭ്യമാണ്.

## സൗജന്യ പ്രോക്സികളെക്കുറിച്ച് കണക്കുകൾ പറയുന്നത്

എൻജിൻ കണ്ട ഓരോ പ്രോക്സിയുടെയും ചരിത്രം സൂക്ഷിക്കുന്നു, അതിനാൽ സൗജന്യ പ്രോക്സികളെക്കുറിച്ചുള്ള പതിവ് അവകാശവാദങ്ങൾ ഊഹിക്കുന്നതിനു പകരം അളക്കാം. 2026-09-05-ന് പൂളിൽ റീഡ്-ഒൺലി ക്വറി: 763,409 പ്രോക്സികളും 115,078,758 പരിശോധനകളും.

- **പ്രവർത്തിക്കുന്ന ഒന്ന് അതിന്റെ പരിശോധനകളിൽ പകുതിയിൽ താഴെ മാത്രമേ പ്രതികരിക്കൂ.** പ്രവർത്തിക്കുന്ന സെറ്റിലെ ഒരു പ്രോക്സി അതിന്റെ സ്വന്തം പരിശോധനകളിൽ 45.5 ശതമാനം വിജയിച്ചു. ഇതുവരെ പിന്തുടർന്ന 765,494 പ്രോക്സികളിൽ (2026-09-06), 667 എണ്ണം അവയുടെ പരിശോധനകളിൽ 90 ശതമാനമോ അതിലധികമോ പ്രതികരിച്ചു; അവ [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list)-ൽ പട്ടികപ്പെടുത്തിയിരിക്കുന്നു.

പ്രായോഗികമായി: സൗജന്യ പ്രോക്സികൾ പൊതു പേജുകൾ, പരീക്ഷണങ്ങൾ, ലൊക്കേഷൻ പരിശോധനകൾ എന്നിവയ്ക്ക് ചെറിയ timeout-ഉം അടുത്ത വരിയിൽ വീണ്ടും ശ്രമിക്കലും വെച്ച് ഉപയോഗിക്കുക. ലോഗിൻ, പേയ്മെന്റ്, അല്ലെങ്കിൽ ബോട്ട് കണ്ടെത്തൽ ഉള്ള ലക്ഷ്യം ഉൾപ്പെടുന്ന എന്തിനും തുടർച്ചയായി പ്രവർത്തിക്കുന്നതും ഇന്റർനെറ്റ് മുഴുവനുമായി പങ്കിടാത്തതുമായ പ്രോക്സി വേണം; കാണുക: [സൗജന്യ പ്രോക്സി മതിയാകാത്തപ്പോൾ](#സൗജനയ-പരോകസി-മതിയാകാതതപപോൾ).

അതെ. MCP സെർവർ, കീയില്ലാത്ത API, llms.txt പേജുകൾ എന്നിവ അതിനായി തന്നെയാണ് നിർമ്മിച്ചത്; കാണുക: [AI അസിസ്റ്റന്റിൽ നിന്ന് ഉപയോഗിക്കുക](#ai-അസിസററനറിൽ-നിനന-ഉപയോഗികകുക).

**സൗജന്യ പ്രോക്സികൾ ഉപയോഗിക്കുന്നത് സുരക്ഷിതമാണോ?**
അവയെ പൊതുവായതും വിശ്വസിക്കാനാകാത്തതുമായി കണക്കാക്കുക. പൊതു പേജുകൾ സ്ക്രാപ്പ് ചെയ്യാനും പരീക്ഷിക്കാനും ലൊക്കേഷൻ പരിശോധിക്കാനും അവ മതി. പാസ്‌വേഡുകൾ, സെഷനുകൾ, പേയ്മെന്റ് ഡാറ്റ എന്നിവ ഒരിക്കലും പൊതു പ്രോക്സി വഴി അയയ്ക്കരുത്: അത് പ്രവർത്തിപ്പിക്കുന്നയാൾക്ക് എൻഡ്-ടു-എൻഡ് എൻക്രിപ്റ്റ് ചെയ്യാത്ത എന്തും വായിക്കാം.

**ഈ പട്ടിക മറ്റ് സൗജന്യ പ്രോക്സി പട്ടികകളിൽ നിന്ന് എങ്ങനെ വ്യത്യസ്തമാണ്?**
ഇവിടത്തെ ഓരോ പ്രോക്സിയും മുഴുവൻ സമയവും വീണ്ടും പരീക്ഷിക്കപ്പെടുകയും അതിന്റെ അളവുകൾ വഹിക്കുകയും ചെയ്യുന്നു, മറ്റ് പട്ടികകൾ ഉപയോഗിക്കുന്ന അതേ പൊതു സ്രോതസ്സുകളിൽ നിന്നാണ് ഈ പട്ടിക നിർമ്മിച്ചത്, അതിനാൽ ഒരൊറ്റ ഫയൽ ആ ശേഖരം മുഴുവൻ മാറ്റിസ്ഥാപിക്കുന്നു. അതിന് പിന്നിലെ ചരിത്രവും പ്രസിദ്ധീകരിച്ചിട്ടുണ്ട്, കാണുക: [സൗജന്യ പ്രോക്സികളെക്കുറിച്ച് കണക്കുകൾ പറയുന്നത്](#സൗജനയ-പരോകസികളെകകുറിചച-കണകകുകൾ-പറയുനനത).

## ഞങ്ങൾ സംയോജിപ്പിക്കുന്ന സ്രോതസ്സുകൾ

എൻജിൻ 100-ലധികം പൊതു പ്രോക്സി സ്രോതസ്സുകളിൽ നിന്ന് ശേഖരിക്കുകയും ഡ്യൂപ്ലിക്കേറ്റുകൾ നീക്കുകയും എല്ലാം പരീക്ഷിക്കുകയും അളവുകൾ ഒരിടത്ത് ചേർക്കുകയും ചെയ്യുന്നു. ഒരു ഡസൻ പൊതു റിപ്പോസിറ്ററികളും പ്രോക്സി സൈറ്റുകളും സ്വയം സ്ക്രാപ്പ് ചെയ്ത് ഒത്തുനോക്കുന്നതിനു പകരം, അവയുടെ പരിശോധിച്ച, ഡ്യൂപ്ലിക്കേറ്റില്ലാത്ത സംയോജനം മുഴുവൻ സമയവും പുതുക്കിയ നിലയിൽ നിങ്ങൾക്ക് കിട്ടുന്നു.

ഞങ്ങൾ ശേഖരിക്കേണ്ട ഒരു പൊതു പ്രോക്സി സ്രോതസ്സ് അറിയാമോ? [ഒരു issue തുറക്കുക](https://github.com/hproxy-com/free-proxy-list/issues), അത് ചേർക്കുന്നത് ഞങ്ങൾ പരിഗണിക്കാം.

## ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു

1. **ശേഖരണം**: ഏതാനും മിനിറ്റുകൾ കൂടുമ്പോൾ 100-ലധികം പൊതു സ്രോതസ്സുകളിൽ നിന്ന് സ്ഥാനാർത്ഥികൾ.

3. **അളവെടുപ്പ്**: പ്രവർത്തിക്കുന്ന ഓരോ പ്രോക്സിയുടെയും രാജ്യം, അജ്ഞാതത്വ നില, കാലതാമസം, അപ്ടൈം.
4. **പ്രസിദ്ധീകരണം**: ഫലം ഇവിടെ ദിവസത്തിൽ പല തവണ, [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list)-ൽ മിനിറ്റുകൾക്കുള്ളിൽ.
