## Hvad hver række fortæller dig

De fleste gratis proxylister giver dig en nøgen `ip:port`. Her bærer hver række også de målinger, der afgør, om proxyen er en forespørgsel værd:

| Felt | Hvad det fortæller |
|-------|-------------------|
| `protocols` | De protokoller, den faktisk svarede på, ud af HTTP, HTTPS, SOCKS4 og SOCKS5 |
| `anonymity` | Transparent, anonym eller elite: om målet kan se din rigtige IP |
| `country` / `city` | Hvor udgangen sidder |
| `latency_ms` | Målt svartid ved seneste kontrol |
| `uptime_24h` / `uptime_7d` | Hvor ofte den svarede, så en proxy, der var oppe én gang, ikke ligner en, der bliver oppe |

Alt det findes i [all.json](../all.json) og [all.csv](../all.csv) og på [livelisten på hproxy.com](https://hproxy.com/free-proxy-list), hvor hver række kan filtreres efter land, protokol, anonymitet og oppetid.

## Brug den i din kode

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl:**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

**Node.js:**

```js
const list = await fetch("https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt")
  .then(r => r.text());
const proxies = list.trim().split("\n");
```

## Brug den fra en AI-assistent

Den samme liste er åben for AI-assistenter og agenter. HProxy kører en MCP-server med tre værktøjer, `proxy_list`, `proxy_check` og `ip_lookup`, oven på det samme nøglefri API, og opsætningen til Claude Code, Claude Desktop, Cursor og Windsurf findes på [hproxy.com/tools/ai](https://hproxy.com/tools/ai). API'et er dokumenteret på [hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list), og hele det gratis API kan være på én markdown-side skrevet til assistenter, [hproxy.com/llms/free-proxy.txt](https://hproxy.com/llms/free-proxy.txt).

Fuld vejledning til en assistent: hent `https://hproxy.com/api/proxy-list?format=json` for hver proxy, der er oppe, og tilføj `protocol=socks5`, `country=US`, `anonymity=elite` eller `min_uptime_pct=90` for at filtrere. Ingen nøgle, ingen tilmelding, CORS åben. Tjek enhver proxy med `https://hproxy.com/api/proxy-check?proxy=ip:port`. Det er offentlige gratis proxyer: regn med, at færre end halvdelen svarer på et givet tidspunkt, sæt en kort timeout, og gå videre til den næste.

Du må bygge listen ind i din egen software, gratis og uden at spørge. Hvis noget ikke virker, er supporten bemandet døgnet rundt på [hproxy.com/contact](https://hproxy.com/contact).

## Hvad tallene siger om gratis proxyer

Motoren gemmer historikken for hver proxy, den nogensinde har set, så de sædvanlige påstande om gratis proxyer kan måles i stedet for at gættes. Læseforespørgsel på puljen 2026-09-05: 763.409 proxyer og 115.078.758 verifikationskontroller.

- **En gratis proxy lever omkring seks dage.** Median levetid på tværs af de 691.179 proxyer, der er døde: 144,5 timer. 22,6 procent var døde inden for deres første time, og 17 procent holdt i mere end en måned.
- **En proxy, der er oppe, svarer på færre end halvdelen af sine kontroller.** En proxy i den oppe mængde bestod 45,5 procent af sine egne verifikationskontroller. Af de 765.494 proxyer, der nogensinde er fulgt (2026-09-06), har 667 svaret på 90 procent af deres kontroller eller mere; de er opført på [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list).
- **De gratis lister på internettet er én pulje.** Den gennemsnitlige oppe proxy optræder i 17,9 af de kilder, vi henter fra, og 94,7 procent optræder i mere end én. At kopiere fra flere lister giver dig de samme proxyer med forskellige datoer.

I praksis: brug gratis proxyer til offentlige sider, test og placeringstjek, med en kort timeout og et nyt forsøg på næste linje. Alt med login, betaling eller et mål, der kører botdetektering, kræver en proxy, der bliver oppe og ikke deles med hele internettet; se [Når en gratis proxy ikke er nok](#når-en-gratis-proxy-ikke-er-nok).

Behandl dem som offentlige og upålidelige. De er fine til at hente offentlige sider, teste og tjekke placering. Send aldrig adgangskoder, sessioner eller betalingsdata gennem en offentlig proxy: den, der driver den, kan læse alt, der ikke er krypteret ende til ende.

**Hvordan adskiller denne liste sig fra andre gratis proxylister?**
Hver proxy her gentestes døgnet rundt og bærer sine målinger, og listen er bygget af de samme offentlige kilder, som de andre lister bruger, så én fil erstatter samlingen. Historikken bag den er også udgivet, se [Hvad tallene siger om gratis proxyer](#hvad-tallene-siger-om-gratis-proxyer).

En gratis proxy deles med alle, der har fundet den samme liste, så de mål, folk går op i, har som regel set den før dig.
