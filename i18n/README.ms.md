## Apa yang diberitahu setiap baris

Kebanyakan senarai proksi percuma hanya memberi anda `ip:port` kosong. Di sini setiap baris turut membawa ukuran yang menentukan sama ada proksi itu berbaloi untuk satu permintaan:

| Medan | Maksudnya |
|-------|-------------------|
| `protocols` | Protokol yang benar-benar dijawabnya, daripada HTTP, HTTPS, SOCKS4 dan SOCKS5 |
| `anonymity` | Telus, tanpa nama atau elite: sama ada sasaran boleh melihat IP sebenar anda |
| `country` / `city` | Di mana titik keluar berada |
| `latency_ms` | Masa tindak balas yang diukur pada semakan terakhir |
| `uptime_24h` / `uptime_7d` | Berapa kerap ia menjawab, supaya proksi yang pernah aktif sekali tidak kelihatan seperti proksi yang kekal aktif |

Semuanya ada dalam [all.json](../all.json) dan [all.csv](../all.csv), dan pada [senarai langsung di hproxy.com](https://hproxy.com/free-proxy-list), di mana setiap baris boleh ditapis mengikut negara, protokol, kerahsiaan dan masa aktif.

## Gunakan dalam kod anda

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl:**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

**Node.js:**

```js
const list = await fetch("https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt")
  .then(r => r.text());
const proxies = list.trim().split("\n");
```

Proksi tidak boleh ditambah melalui pull request: senarai dijana semula daripada enjin pengesahan pada setiap penyegaran, jadi entri yang di-commit akan ditulis ganti oleh yang seterusnya. Sumbangan yang berguna ialah [sumber proksi awam](../CONTRIBUTING.md) untuk diambil oleh enjin.

## Undang-undang

Proksi ini digabungkan daripada sumber yang tersedia secara awam. Kami tidak mengimbas untuk mencarinya, dan kami tidak menyimpan apa-apa tentang peranti di sebaliknya. Ia disediakan seadanya, tanpa jaminan, untuk kegunaan yang sah sahaja. Anda bertanggungjawab atas cara anda menggunakannya: patuhi Dasar Penggunaan Boleh Terima GitHub dan undang-undang tempatan anda, dan jangan sesekali salurkan kata laluan atau data sensitif melalui proksi awam. Jika sesuatu alamat IP itu milik anda dan anda mahu ia dibuang, buka issue.
