## Mitä jokainen rivi kertoo

Useimmat ilmaiset proxylistat antavat pelkän `ip:port`-parin. Täällä jokaisella rivillä on myös mittaukset, jotka ratkaisevat, onko proxy pyynnön arvoinen:

| Kenttä | Mitä se kertoo |
|-------|-------------------|
| `protocols` | Protokollat, joilla se oikeasti vastasi, joukosta HTTP, HTTPS, SOCKS4 ja SOCKS5 |
| `anonymity` | Läpinäkyvä, anonyymi tai elite: näkeekö kohde oikean IP-osoitteesi |
| `country` / `city` | Missä ulostulo sijaitsee |
| `latency_ms` | Viimeisimmässä tarkistuksessa mitattu vasteaika |
| `uptime_24h` / `uptime_7d` | Kuinka usein se vastasi, jotta kerran toiminut proxy ei näytä siltä, joka pysyy toiminnassa |

Kaikki tämä on tiedostoissa [all.json](../all.json) ja [all.csv](../all.csv) sekä [hproxy.comin live-listalla](https://hproxy.com/free-proxy-list), jossa jokaisen rivin voi suodattaa maan, protokollan, anonymiteetin ja käytettävyyden mukaan.

## Käytä sitä koodissasi

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl:**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

**Node.js:**

```js
const list = await fetch("https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt")
  .then(r => r.text());
const proxies = list.trim().split("\n");
```

## Mitä luvut kertovat ilmaisista proxyista

Moottori säilyttää jokaisen koskaan näkemänsä proxyn historian, joten tavanomaiset väitteet ilmaisista proxyista voidaan mitata arvailun sijaan. Vain luku -kysely pooliin 2026-09-05: 763 409 proxya ja 115 078 758 tarkistusta.

- **Ilmainen proxy elää noin kuusi päivää.** Eliniän mediaani 691 179 kuolleen proxyn joukossa: 144,5 tuntia. 22,6 prosenttia kuoli ensimmäisen tuntinsa aikana, ja 17 prosenttia kesti yli kuukauden.
- **Toiminnassa oleva proxy vastaa alle puoleen tarkistuksistaan.** Toiminnassa olevan joukon proxy läpäisi 45,5 prosenttia omista tarkistuksistaan. Kaikkiaan 765 494 seuratusta proxysta (2026-09-06) 667 vastasi vähintään 90 prosenttiin tarkistuksistaan; ne on listattu osoitteessa [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list).
- **Internetin ilmaiset listat ovat yksi pooli.** Keskimääräinen toiminnassa oleva proxy esiintyy 17,9:ssä lähteistä, joista noudamme, ja 94,7 prosenttia esiintyy useammassa kuin yhdessä. Useista listoista kopioiminen antaa samat proxyt eri päivämäärillä.

Käytännössä: käytä ilmaisia proxyja julkisiin sivuihin, testeihin ja sijaintitarkistuksiin lyhyellä aikakatkaisulla ja uudella yrityksellä seuraavalla rivillä. Kohtele niitä julkisina ja epäluotettavina. Ne sopivat julkisten sivujen hakemiseen, testaamiseen ja sijaintitarkistuksiin. Älä koskaan lähetä salasanoja, istuntoja tai maksutietoja julkisen proxyn kautta: sen ylläpitäjä voi lukea kaiken, mitä ei ole salattu päästä päähän.

**Miten tämä lista eroaa muista ilmaisista proxylistoista?**
Jokainen proxy täällä testataan uudelleen kellon ympäri ja kantaa mittauksensa, ja lista on koottu samoista julkisista lähteistä, joita muut listat käyttävät, joten yksi tiedosto korvaa koko kokoelman. ## Kun ilmainen proxy ei riitä

Ilmainen proxy jaetaan kaikkien saman listan löytäneiden kanssa, joten kohteet, joista ihmiset oikeasti välittävät, ovat yleensä nähneet sen ennen sinua. Kun työ vaatii proxyn, joka pysyy toiminnassa, säilyttää istunnon eikä ole jaettu koko internetin kanssa, [HProxy](https://hproxy.com) myy residential-, ISP-, mobiili- ja datakeskusproxyja gigatavuittain, alkaen $0.44 per GB.
