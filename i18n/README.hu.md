## Mit árul el egy sor

A legtöbb ingyenes proxylista egy csupasz `ip:port` bejegyzést ad. Itt minden sor hordozza azokat a méréseket is, amelyek eldöntik, megér-e a proxy egy kérést:

| Mező | Mit jelent |
|-------|-------------------|
| `protocols` | Azok a protokollok, amelyeken ténylegesen válaszolt, a HTTP, HTTPS, SOCKS4 és SOCKS5 közül |
| `anonymity` | Átlátszó, anonim vagy elite: látja-e a célpont az Ön valódi IP-címét |
| `country` / `city` | Hol található a kilépési pont |
| `latency_ms` | A legutóbbi ellenőrzéskor mért válaszidő |
| `uptime_24h` / `uptime_7d` | Milyen gyakran válaszolt, hogy az egyszer élt proxy ne tűnjön olyannak, amelyik folyamatosan él |

Mindez megtalálható az [all.json](../all.json) és az [all.csv](../all.csv) fájlban, valamint a [hproxy.com élő listáján](https://hproxy.com/free-proxy-list), ahol minden sor szűrhető ország, protokoll, anonimitás és rendelkezésre állás szerint.
