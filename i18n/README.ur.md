## ہر قطار آپ کو کیا بتاتی ہے

زیادہ تر مفت پراکسی فہرستیں آپ کو محض ایک ننگا `ip:port` تھما دیتی ہیں۔ یہاں ہر قطار میں وہ پیمائشیں بھی ہیں جو طے کرتی ہیں کہ پراکسی ایک درخواست کے قابل ہے یا نہیں:

| فیلڈ | اس کا مطلب |
|-------|-------------------|
| `protocols` | HTTP، HTTPS، SOCKS4 اور SOCKS5 میں سے وہ پروٹوکول جن پر اس نے واقعی جواب دیا |
| `anonymity` | شفاف، گمنام یا elite: کیا ہدف آپ کا اصل IP دیکھ سکتا ہے |
| `country` / `city` | خروج کہاں واقع ہے |
| `latency_ms` | آخری جانچ میں ناپا گیا جوابی وقت |
| `uptime_24h` / `uptime_7d` | اس نے کتنی بار جواب دیا، تاکہ ایک بار فعال رہنے والی پراکسی اس پراکسی جیسی نہ لگے جو فعال رہتی ہے |

یہ سب [all.json](../all.json) اور [all.csv](../all.csv) میں ہے، اور [hproxy.com کی لائیو فہرست](https://hproxy.com/free-proxy-list) پر بھی، جہاں ہر قطار کو ملک، پروٹوکول، گمنامی اور اپ ٹائم کے لحاظ سے چھانا جا سکتا ہے۔

## اپنے کوڈ میں استعمال کریں

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl:**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

## اعداد و شمار مفت پراکسیوں کے بارے میں کیا کہتے ہیں

انجن اب تک دیکھی ہر پراکسی کی تاریخ رکھتا ہے، اس لیے مفت پراکسیوں کے بارے میں عام دعووں کو اندازے کے بجائے ناپا جا سکتا ہے۔ 2026-09-05 کو پول پر صرف پڑھنے والی کوئری: 763,409 پراکسیاں اور 115,078,758 تصدیقی جانچیں۔

- **ایک مفت پراکسی تقریباً چھ دن جیتی ہے۔** مر چکی 691,179 پراکسیوں میں عمر کا وسطانیہ: 144.5 گھنٹے۔ 22.6 فیصد پہلے ہی گھنٹے میں مر گئیں، اور 17 فیصد ایک مہینے سے زیادہ ٹکیں۔
- **ایک فعال پراکسی اپنی آدھی سے کم جانچوں کا جواب دیتی ہے۔** فعال سیٹ کی ایک پراکسی اپنی تصدیقی جانچوں میں سے 45.5 فیصد میں کامیاب ہوئی۔ اب تک ٹریک کی گئی 765,494 پراکسیوں (2026-09-06) میں سے 667 نے اپنی 90 فیصد یا اس سے زیادہ جانچوں کا جواب دیا؛ وہ [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) پر درج ہیں۔
- **انٹرنیٹ کی مفت فہرستیں ایک ہی پول ہیں۔** اوسط فعال پراکسی ہمارے حاصل کردہ ذرائع میں سے 17.9 پر نظر آتی ہے، اور 94.7 فیصد ایک سے زیادہ پر نظر آتی ہیں۔ کئی فہرستوں سے کاپی کرنے پر آپ کو وہی پراکسیاں مختلف تاریخوں کے ساتھ ملتی ہیں۔

عملی طور پر: مفت پراکسیاں عوامی صفحات، ٹیسٹ اور مقام کی جانچ کے لیے استعمال کریں، مختصر ٹائم آؤٹ اور اگلی سطر پر دوبارہ کوشش کے ساتھ۔ جس چیز میں لاگ ان، ادائیگی، یا بوٹ کی شناخت والا ہدف ہو اسے ایسی پراکسی چاہیے جو فعال رہے اور پورے انٹرنیٹ کے ساتھ شیئر نہ ہو؛ دیکھیں [جب مفت پراکسی کافی نہ ہو](#جب-مفت-پراکسی-کافی-نہ-ہو)۔

## عمومی سوالات

**اس فہرست میں کتنی مفت پراکسیاں ہیں؟**
اب تک 769,489 ٹریک کی گئی ہیں۔ 6,350 اس منٹ فعال ہیں اور 26,218 نے پچھلے 48 گھنٹوں میں جواب دیا، اور شائع شدہ فائلوں میں بالکل یہی ہیں۔

**کون سے پروٹوکول معاون ہیں؟**
HTTP، HTTPS، SOCKS4 اور SOCKS5۔ ہر پراکسی پر وہی پروٹوکول لیبل ہیں جن پر اس نے واقعی جواب دیا، نہ کہ وہ جن کے تحت وہ درج تھی۔

**فہرست کتنی بار اپ ڈیٹ ہوتی ہے؟**
امیدوار ہر چند منٹ میں ذرائع سے حاصل کیے جاتے ہیں اور چوبیس گھنٹے دوبارہ جانچے جاتے ہیں۔ یہ ریپوزٹری دن میں کئی بار تازہ ہوتی ہے، اور [hproxy.com کی لائیو فہرست](https://hproxy.com/free-proxy-list) منٹوں میں نتائج دکھاتی ہے۔

**کیا پراکسیاں گمنام ہیں؟**
ہر ایک کو اس بنیاد پر شفاف، گمنام یا elite درجہ دیا جاتا ہے کہ ہدف آپ کا اصل IP دیکھتا ہے یا نہیں۔ `all.json` یا `all.csv` میں `anonymity` فیلڈ پر چھانیں، یا `elite.txt` لے لیں۔

**Python میں پراکسی کیسے استعمال کروں؟**
اوپر [اپنے کوڈ میں استعمال کریں](#اپنے-کوڈ-میں-استعمال-کریں) دیکھیں۔ `all.txt` حاصل کریں، ایک سطر چنیں، اور اسے `requests` کو `http` اور `https` پراکسی کے طور پر دیں۔ ٹائم آؤٹ رکھیں اور ناکامی پر اگلی سطر پر بڑھیں، کیونکہ مفت پراکسی اپنی آدھی سے کم جانچوں کا جواب دیتی ہے۔

**کیا مجھے API کلید یا اکاؤنٹ چاہیے؟**
نہیں۔ نہ یہاں کی خام فائلوں کو اور نہ [hproxy.com کے مفت API](https://hproxy.com/docs/free-proxy-list) کو سائن اپ یا کلید چاہیے۔

**کیا کوئی AI اسسٹنٹ یا ایجنٹ یہ فہرست استعمال کر سکتا ہے؟**
ہاں۔ MCP سرور، بغیر کلید API اور llms.txt صفحات اسی کے لیے بنے ہیں؛ دیکھیں [AI اسسٹنٹ سے استعمال کریں](#ai-اسسٹنٹ-سے-استعمال-کریں)۔

**کیا مفت پراکسیاں استعمال کرنا محفوظ ہے؟**
انہیں عوامی اور ناقابل اعتبار سمجھیں۔ عوامی صفحات اسکریپ کرنے، ٹیسٹ اور مقام کی جانچ کے لیے یہ ٹھیک ہیں۔ عوامی پراکسی سے کبھی پاس ورڈ، سیشن یا ادائیگی کا ڈیٹا نہ بھیجیں: جو اسے چلاتا ہے وہ ہر وہ چیز پڑھ سکتا ہے جو اینڈ ٹو اینڈ انکرپٹڈ نہیں۔

**یہ فہرست دوسری مفت پراکسی فہرستوں سے کیسے مختلف ہے؟**
یہاں ہر پراکسی چوبیس گھنٹے دوبارہ جانچی جاتی ہے اور اپنی پیمائشیں ساتھ رکھتی ہے، اور فہرست انہی عوامی ذرائع سے بنی ہے جو دوسری فہرستیں استعمال کرتی ہیں، اس لیے ایک فائل پورے مجموعے کی جگہ لے لیتی ہے۔ اس کے پیچھے کی تاریخ بھی شائع شدہ ہے، دیکھیں [اعداد و شمار مفت پراکسیوں کے بارے میں کیا کہتے ہیں](#اعداد-و-شمار-مفت-پراکسیوں-کے-بارے-میں-کیا-کہتے-ہیں)۔

## وہ ذرائع جنہیں ہم یکجا کرتے ہیں

انجن 100 سے زیادہ عوامی پراکسی ذرائع سے حاصل کرتا ہے، ڈپلیکیٹ ہٹاتا ہے، سب کچھ جانچتا ہے اور پیمائشیں ایک جگہ جوڑ دیتا ہے۔ درجن بھر عوامی ریپوزٹریوں اور پراکسی سائٹوں کو خود اسکریپ کر کے آپس میں ملانے کے بجائے، آپ کو ان کا جانچا ہوا، ڈپلیکیٹ سے پاک اتحاد ملتا ہے، جو چوبیس گھنٹے تازہ ہوتا ہے۔

کوئی ایسا عوامی پراکسی ذریعہ جانتے ہیں جس سے ہمیں حاصل کرنا چاہیے؟ [ایک issue کھولیں](https://github.com/hproxy-com/free-proxy-list/issues) اور ہم اسے شامل کرنے پر غور کریں گے۔

## یہ کیسے کام کرتا ہے

1. **جمع کرنا**: ہر چند منٹ میں 100 سے زیادہ عوامی ذرائع سے امیدوار۔
2. **تصدیق**: ہر پراکسی HTTP، HTTPS، SOCKS4 اور SOCKS5 پر، چوبیس گھنٹے۔
3. **پیمائش**: ہر فعال پراکسی کا ملک، گمنامی کا درجہ، تاخیر، اپ ٹائم۔
4. **اشاعت**: نتیجہ یہاں دن میں کئی بار، اور [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) پر منٹوں میں۔
