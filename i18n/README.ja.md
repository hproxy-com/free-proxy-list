## 各行が教えてくれること

ほとんどの無料プロキシリストは素の `ip:port` しか渡してくれません。ここでは各行に、そのプロキシがリクエストに値するかを判断するための計測値が付いています。

| フィールド | 意味 |
|-------|-------------------|
| `protocols` | HTTP、HTTPS、SOCKS4、SOCKS5 のうち実際に応答したプロトコル |
| `anonymity` | 透過、匿名、高匿名のいずれか。接続先があなたの本当の IP を見られるかどうか |
| `country` / `city` | 出口の所在地 |
| `latency_ms` | 最後のチェックで計測した応答時間 |
| `uptime_24h` / `uptime_7d` | どのくらいの頻度で応答したか。一度だけ稼働したプロキシが、稼働し続けるプロキシと同じに見えないように |

これらはすべて [all.json](../all.json) と [all.csv](../all.csv) に入っており、[hproxy.com のライブリスト](https://hproxy.com/free-proxy-list) でも国、プロトコル、匿名性、稼働率で各行を絞り込めます。

**Python（requests）:**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",

print(r.text)
```

## AI アシスタントから使う

同じリストは AI アシスタントやエージェントにも開かれています。HProxy は同じキー不要の API の上で、`proxy_list`、`proxy_check`、`ip_lookup` の 3 つのツールを持つ MCP サーバーを運用しており、Claude Code、Claude Desktop、Cursor、Windsurf 向けの設定は [hproxy.com/tools/ai](https://hproxy.com/tools/ai) にあります。API の文書は [hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list) にあり、無料 API 全体はアシスタント向けに書かれた 1 枚の markdown ページ [hproxy.com/llms/free-proxy.txt](https://hproxy.com/llms/free-proxy.txt) に収まっています。

アシスタント向けの完全な手順: `https://hproxy.com/api/proxy-list?format=json` を取得すると稼働中のプロキシがすべて得られ、`protocol=socks5`、`country=US`、`anonymity=elite`、`min_uptime_pct=90` を付けると絞り込めます。キー不要、登録不要、CORS 開放。任意のプロキシは `https://hproxy.com/api/proxy-check?proxy=ip:port` でチェックできます。これらは公開の無料プロキシです。どの瞬間も応答するのは半数未満と見込み、短いタイムアウトを設定して次へ進んでください。

このリストは、無料で、許可を求めることなく、自分のソフトウェアに組み込めます。動かないことがあれば、[hproxy.com/contact](https://hproxy.com/contact) のサポートが 24 時間体制で対応します。

## 数字が語る無料プロキシの実態

エンジンは見てきたすべてのプロキシの履歴を保持しているため、無料プロキシについてよく言われることを、推測ではなく計測で確かめられます。2026-09-05 のプールに対する読み取り専用クエリ: 763,409 件のプロキシ、115,078,758 回の検証チェック。

- **無料プロキシの寿命はおよそ 6 日。** 消滅した 691,179 件のプロキシの寿命の中央値は 144.5 時間。22.6% は最初の 1 時間以内に消え、17% は 1 か月以上持ちました。
- **稼働中のプロキシでもチェックの半分未満にしか応答しません。** 稼働セット内のプロキシは自身の検証チェックの 45.5% にしか合格していません。これまでに追跡した 765,494 件（2026-09-06）のうち、チェックの 90% 以上に応答したのは 667 件で、[hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) に掲載しています。
- **インターネット上の無料リストは 1 つのプールです。** 稼働中のプロキシは平均して当社が収集するソースのうち 17.9 か所に載っており、94.7% は複数のソースに載っています。複数のリストからコピーしても、日付が違うだけの同じプロキシが手に入るだけです。

実用上のポイント: 無料プロキシは公開ページ、テスト、所在地の確認に、短いタイムアウトと次の行での再試行を前提に使ってください。ログイン、決済、ボット検出のある接続先には、稼働し続け、インターネット全体と共有されていないプロキシが必要です。[無料プロキシでは足りないとき](#無料プロキシでは足りないとき) を参照してください。

## よくある質問

**このリストには無料プロキシが何件ありますか？**
これまでに 771,161 件を追跡しました。5,819 件が今この瞬間に稼働中で、32,628 件が過去 48 時間以内に応答しており、公開ファイルにはちょうどその分が入っています。

**対応しているプロトコルは？**
HTTP、HTTPS、SOCKS4、SOCKS5 です。各プロキシには、掲載時のプロトコルではなく、実際に応答したプロトコルがラベル付けされています。

**リストはどのくらいの頻度で更新されますか？**
候補は数分ごとにソースから集められ、24 時間体制で再テストされます。このリポジトリは 1 日に数回更新され、[hproxy.com のライブリスト](https://hproxy.com/free-proxy-list) には数分以内に結果が反映されます。

**プロキシは匿名ですか？**
各プロキシは、接続先があなたの本当の IP を見られるかどうかで、透過、匿名、高匿名に分類されます。`all.json` または `all.csv` の `anonymity` フィールドで絞り込むか、`elite.txt` を使ってください。

**Python でプロキシを使うには？**
上の [コードで使う](#コードで使う) を参照してください。`all.txt` を取得し、1 行選んで、`http` と `https` のプロキシとして `requests` に渡します。無料プロキシはチェックの半分未満にしか応答しないので、タイムアウトを設定し、失敗したら次の行へ進んでください。

**API キーやアカウントは必要ですか？**
いいえ。ここの生ファイルも [hproxy.com の無料 API](https://hproxy.com/docs/free-proxy-list) も、登録もキーも不要です。

**AI アシスタントやエージェントはこのリストを使えますか？**
はい。MCP サーバー、キー不要の API、llms.txt ページはそのために用意されています。[AI アシスタントから使う](#ai-アシスタントから使う) を参照してください。

**無料プロキシは安全に使えますか？**
公開されていて信頼できないものとして扱ってください。公開ページのスクレイピング、テスト、所在地の確認には問題ありません。パスワード、セッション、決済データを公開プロキシに通してはいけません。運営者はエンドツーエンドで暗号化されていないものをすべて読めます。

**このリストは他の無料プロキシリストと何が違いますか？**
ここのプロキシはすべて 24 時間体制で再テストされ計測値を持ち、リストは他のリストと同じ公開ソースから構築されているため、1 つのファイルで寄せ集めを置き換えられます。背景にある履歴も公開しています。[数字が語る無料プロキシの実態](#数字が語る無料プロキシの実態) を参照してください。

## 集約しているソース

エンジンは 100 以上の公開プロキシソースから収集し、重複を除き、すべてをテストし、計測値を 1 か所にまとめます。十数個の公開リポジトリやプロキシサイトを自分でスクレイピングして突き合わせる代わりに、検証済みで重複のない和集合を、24 時間体制で更新された状態で受け取れます。

収集すべき公開プロキシソースをご存じですか？[issue を開いてください](https://github.com/hproxy-com/free-proxy-list/issues)。追加を検討します。

## 仕組み

1. **集約**: 数分ごとに 100 以上の公開ソースから候補を集めます。
2. **検証**: 各プロキシを HTTP、HTTPS、SOCKS4、SOCKS5 で 24 時間体制でテストします。
3. **計測**: 稼働中の各プロキシの国、匿名性の等級、レイテンシ、稼働率を記録します。
4. **公開**: 結果をここに 1 日数回、[hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) には数分以内に公開します。

## 無料プロキシでは足りないとき

無料プロキシは同じリストを見つけた全員と共有されるため、人々が本当に使いたい接続先は、たいていあなたより先にそれを見ています。稼働し続け、セッションを保ち、インターネット全体と共有されていないプロキシが必要な仕事のために、[HProxy](https://hproxy.com) はレジデンシャル、ISP、モバイル、データセンターのプロキシをギガバイト単位、1 GB あたり $0.44 から販売しています。同じサイトのプロキシチェッカーとライブリストは無料のままです。
