## Ce que chaque ligne vous dit

La plupart des listes de proxys gratuits vous donnent un simple `ip:port`. Ici, chaque ligne porte aussi les mesures qui décident si le proxy vaut une requête :

| Champ | Ce qu'il indique |
|-------|-------------------|
| `protocols` | Les protocoles sur lesquels il a réellement répondu, parmi HTTP, HTTPS, SOCKS4 et SOCKS5 |
| `anonymity` | Transparent, anonyme ou elite : si la cible peut voir votre vraie IP |
| `country` / `city` | Où se trouve la sortie |
| `latency_ms` | Temps de réponse mesuré lors de la dernière vérification |
| `uptime_24h` / `uptime_7d` | À quelle fréquence il a répondu, pour qu'un proxy actif une seule fois ne ressemble pas à un proxy qui reste actif |

Tout cela se trouve dans [all.json](../all.json) et [all.csv](../all.csv), et sur la [liste en direct de hproxy.com](https://hproxy.com/free-proxy-list), où chaque ligne peut être filtrée par pays, protocole, anonymat et disponibilité.

## L'utiliser dans votre code

**Python (requests) :**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl :**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

**Node.js :**

```js
const list = await fetch("https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt")

const proxies = list.trim().split("\n");
```

Traitez-les comme publics et non fiables. Ils conviennent pour récupérer des pages publiques, tester et vérifier une localisation. **En quoi cette liste diffère-t-elle des autres listes de proxys gratuits ?**
Chaque proxy ici est retesté en continu et porte ses mesures, et la liste est construite à partir des mêmes sources publiques que les autres listes, si bien qu'un seul fichier remplace la collection.
