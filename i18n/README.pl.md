## Co mówi każdy wiersz

Większość list darmowych proxy daje gołe `ip:port`. Tu każdy wiersz niesie też pomiary, które decydują, czy proxy jest warte żądania:

| Pole | Co oznacza |
|-------|-------------------|
| `protocols` | Protokoły, na których naprawdę odpowiedziało, spośród HTTP, HTTPS, SOCKS4 i SOCKS5 |
| `anonymity` | Przezroczyste, anonimowe lub elite: czy strona docelowa widzi Wasz prawdziwy adres IP |
| `country` / `city` | Gdzie znajduje się wyjście |
| `latency_ms` | Zmierzony czas odpowiedzi przy ostatnim sprawdzeniu |
| `uptime_24h` / `uptime_7d` | Jak często odpowiadało, żeby proxy, które działało raz, nie wyglądało jak takie, które działa stale |

Wszystko to jest w [all.json](../all.json) i [all.csv](../all.csv) oraz na [liście na żywo na hproxy.com](https://hproxy.com/free-proxy-list), gdzie każdy wiersz można filtrować według kraju, protokołu, anonimowości i dostępności.

Nie. Ani surowe pliki tutaj, ani [darmowe API na hproxy.com](https://hproxy.com/docs/free-proxy-list) nie wymagają rejestracji ani klucza.
