## Τι σας λέει κάθε γραμμή

Οι περισσότερες λίστες δωρεάν proxy σάς δίνουν ένα γυμνό `ip:port`. Εδώ κάθε γραμμή φέρει και τις μετρήσεις που κρίνουν αν το proxy αξίζει ένα αίτημα:

| Πεδίο | Τι δηλώνει |
|-------|-------------------|
| `protocols` | Τα πρωτόκολλα στα οποία απάντησε πραγματικά, από τα HTTP, HTTPS, SOCKS4 και SOCKS5 |
| `anonymity` | Διαφανές, ανώνυμο ή elite: αν ο στόχος μπορεί να δει την πραγματική σας IP |
| `country` / `city` | Πού βρίσκεται η έξοδος |
| `latency_ms` | Μετρημένος χρόνος απόκρισης στον τελευταίο έλεγχο |
| `uptime_24h` / `uptime_7d` | Πόσο συχνά απάντησε, ώστε ένα proxy που ήταν ζωντανό μία φορά να μη μοιάζει με ένα που μένει ζωντανό |

Όλα αυτά βρίσκονται στα [all.json](../all.json) και [all.csv](../all.csv), και στη [ζωντανή λίστα στο hproxy.com](https://hproxy.com/free-proxy-list), όπου κάθε γραμμή φιλτράρεται κατά χώρα, πρωτόκολλο, ανωνυμία και διαθεσιμότητα.

## Τι λένε οι αριθμοί για τα δωρεάν proxy

Η μηχανή κρατά το ιστορικό κάθε proxy που έχει δει ποτέ, οπότε οι συνήθεις ισχυρισμοί για τα δωρεάν proxy μπορούν να μετρηθούν αντί να εικάζονται. Ερώτημα μόνο για ανάγνωση στη δεξαμενή στις 2026-09-05: 763.409 proxy και 115.078.758 έλεγχοι επαλήθευσης.

- **Ένα δωρεάν proxy ζει περίπου έξι ημέρες.** Διάμεση διάρκεια ζωής στα 691.179 proxy που πέθαναν: 144,5 ώρες. Το 22,6 τοις εκατό πέθανε μέσα στην πρώτη ώρα, και το 17 τοις εκατό άντεξε πάνω από έναν μήνα.
- **Ένα ζωντανό proxy απαντά σε λιγότερους από τους μισούς ελέγχους του.** Ένα proxy του ζωντανού συνόλου πέρασε το 45,5 τοις εκατό των δικών του ελέγχων επαλήθευσης. Από τα 765.494 proxy που παρακολουθήθηκαν ποτέ (2026-09-06), 667 απάντησαν στο 90 τοις εκατό των ελέγχων τους ή περισσότερο· βρίσκονται στο [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list).
- **Οι δωρεάν λίστες του διαδικτύου είναι μία δεξαμενή.** Το μέσο ζωντανό proxy εμφανίζεται σε 17,9 από τις πηγές που συλλέγουμε, και το 94,7 τοις εκατό εμφανίζεται σε περισσότερες από μία. Η αντιγραφή από πολλές λίστες σάς δίνει τα ίδια proxy με διαφορετικές ημερομηνίες.

Στην πράξη: χρησιμοποιήστε δωρεάν proxy για δημόσιες σελίδες, δοκιμές και ελέγχους τοποθεσίας, με σύντομο χρονικό όριο και νέα προσπάθεια στην επόμενη γραμμή. Οτιδήποτε με σύνδεση, πληρωμή ή στόχο με ανίχνευση bot χρειάζεται ένα proxy που μένει ζωντανό και δεν μοιράζεται με όλο το διαδίκτυο· δείτε [Όταν ένα δωρεάν proxy δεν αρκεί](#όταν-ένα-δωρεάν-proxy-δεν-αρκεί).

Καθένα βαθμολογείται ως διαφανές, ανώνυμο ή elite ανάλογα με το αν ο στόχος βλέπει την πραγματική σας IP. Φιλτράρετε με το πεδίο `anonymity` στο `all.json` ή στο `all.csv`, ή πάρτε το `elite.txt`.

**Πώς χρησιμοποιώ ένα proxy στην Python;**
Δείτε [Χρήση στον κώδικά σας](#χρήση-στον-κώδικά-σας) παραπάνω. Κατεβάστε το `all.txt`, διαλέξτε μια γραμμή και δώστε τη στο `requests` ως proxy `http` και `https`. Ορίστε χρονικό όριο και σε αποτυχία περάστε στην επόμενη γραμμή, γιατί ένα δωρεάν proxy απαντά σε λιγότερους από τους μισούς ελέγχους του.

**Χρειάζομαι κλειδί API ή λογαριασμό;**
Όχι. Ούτε τα ακατέργαστα αρχεία εδώ ούτε το [δωρεάν API στο hproxy.com](https://hproxy.com/docs/free-proxy-list) χρειάζονται εγγραφή ή κλειδί.

**Μπορεί ένας βοηθός ή πράκτορας AI να χρησιμοποιήσει αυτή τη λίστα;**
Ναι. Ο διακομιστής MCP, το API χωρίς κλειδί και οι σελίδες llms.txt είναι φτιαγμένα γι' αυτό· δείτε [Χρήση από βοηθό AI](#χρήση-από-βοηθό-ai).

**Είναι ασφαλή τα δωρεάν proxy;**
Αντιμετωπίστε τα ως δημόσια και μη αξιόπιστα. Είναι κατάλληλα για ανάκτηση δημόσιων σελίδων, δοκιμές και ελέγχους τοποθεσίας. Ποτέ μη στέλνετε κωδικούς, συνεδρίες ή στοιχεία πληρωμής μέσα από δημόσιο proxy: όποιος το λειτουργεί μπορεί να διαβάσει ό,τι δεν είναι κρυπτογραφημένο από άκρο σε άκρο.

**Σε τι διαφέρει αυτή η λίστα από άλλες λίστες δωρεάν proxy;**
Κάθε proxy εδώ επανελέγχεται όλο το εικοσιτετράωρο και φέρει τις μετρήσεις του, και η λίστα είναι χτισμένη από τις ίδιες δημόσιες πηγές που χρησιμοποιούν οι άλλες λίστες, οπότε ένα αρχείο αντικαθιστά τη συλλογή. Το ιστορικό πίσω της είναι επίσης δημοσιευμένο, δείτε [Τι λένε οι αριθμοί για τα δωρεάν proxy](#τι-λένε-οι-αριθμοί-για-τα-δωρεάν-proxy).

## Οι πηγές που συγκεντρώνουμε

Η μηχανή συλλέγει από περισσότερες από 100 δημόσιες πηγές proxy, αφαιρεί τα διπλότυπα, δοκιμάζει τα πάντα και συγκεντρώνει τις μετρήσεις σε ένα σημείο. Αντί να σαρώνετε μόνοι σας δεκάδες δημόσια αποθετήρια και ιστότοπους proxy και να τα διασταυρώνετε, παίρνετε την ελεγμένη ένωσή τους χωρίς διπλότυπα, ανανεωμένη όλο το εικοσιτετράωρο.

Ξέρετε μια δημόσια πηγή proxy από την οποία θα έπρεπε να συλλέγουμε; [Ανοίξτε ένα issue](https://github.com/hproxy-com/free-proxy-list/issues) και θα εξετάσουμε την προσθήκη της.

## Πώς λειτουργεί

1. **Συγκέντρωση** υποψηφίων από περισσότερες από 100 δημόσιες πηγές, κάθε λίγα λεπτά.
2. **Επαλήθευση** κάθε proxy μέσω HTTP, HTTPS, SOCKS4 και SOCKS5, όλο το εικοσιτετράωρο.
3. **Μέτρηση** κάθε ζωντανού proxy: χώρα, βαθμός ανωνυμίας, καθυστέρηση, διαθεσιμότητα.
4. **Δημοσίευση** του αποτελέσματος εδώ αρκετές φορές την ημέρα, και στο [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) μέσα σε λίγα λεπτά.

Όταν η δουλειά χρειάζεται ένα proxy που μένει ζωντανό, κρατά συνεδρία και δεν έχει μοιραστεί με όλο το διαδίκτυο, η [HProxy](https://hproxy.com) πουλά residential, ISP, mobile και datacenter proxy ανά gigabyte, από $0.44 ανά GB.
