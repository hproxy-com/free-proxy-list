## Hər sətir sizə nə deyir

Pulsuz proxy siyahılarının çoxu sizə çılpaq bir `ip:port` verir. Burada hər sətir proxy-nin bir sorğuya dəyib-dəymədiyini müəyyən edən ölçmələri də daşıyır:

| Sahə | Nə bildirir |
|-------|-------------------|
| `protocols` | HTTP, HTTPS, SOCKS4 və SOCKS5 arasından həqiqətən cavab verdiyi protokollar |
| `anonymity` | Şəffaf, anonim və ya elite: hədəfin əsl IP-nizi görüb-görmədiyi |
| `country` / `city` | Çıxışın yerləşdiyi yer |
| `latency_ms` | Son yoxlamada ölçülən cavab müddəti |
| `uptime_24h` / `uptime_7d` | Nə qədər tez-tez cavab verdiyi; beləliklə bir dəfə işləyən proxy daim işləyən proxy kimi görünmür |

Bunların hamısı [all.json](../all.json) və [all.csv](../all.csv) fayllarında, həmçinin hər sətrin ölkə, protokol, anonimlik və işləmə müddətinə görə süzülə bildiyi [hproxy.com-dakı canlı siyahıda](https://hproxy.com/free-proxy-list) var.

## Kodunuzda istifadə edin

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```
