## 每一行告诉你什么

大多数免费代理列表只给你一个光秃秃的 `ip:port`。这里的每一行还带有决定该代理是否值得一试的测量数据：

| 字段 | 含义 |
|-------|-------------------|
| `protocols` | 它实际响应的协议，在 HTTP、HTTPS、SOCKS4 和 SOCKS5 之中 |
| `anonymity` | 透明、匿名或高匿：目标能否看到你的真实 IP |
| `country` / `city` | 出口所在的位置 |
| `latency_ms` | 上次检测时测得的响应时间 |
| `uptime_24h` / `uptime_7d` | 它响应检测的频率，这样只上线过一次的代理不会看起来像一直在线的代理 |

以上全部都在 [all.json](../all.json) 和 [all.csv](../all.csv) 里，也在 [hproxy.com 的实时列表](https://hproxy.com/free-proxy-list) 上，那里每一行都可以按国家、协议、匿名等级和在线率筛选。
