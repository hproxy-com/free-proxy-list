## 每一列告訴你什麼

大多數免費代理清單只給你一個光禿禿的 `ip:port`。這裡的每一列還帶有決定該代理是否值得一試的測量資料：

| 欄位 | 含義 |
|-------|-------------------|
| `protocols` | 它實際回應的協定，在 HTTP、HTTPS、SOCKS4 和 SOCKS5 之中 |
| `anonymity` | 透明、匿名或高匿：目標能否看到你的真實 IP |
| `country` / `city` | 出口所在的位置 |
| `latency_ms` | 上次檢測時測得的回應時間 |
| `uptime_24h` / `uptime_7d` | 它回應檢測的頻率，這樣只上線過一次的代理不會看起來像一直在線的代理 |

以上全部都在 [all.json](../all.json) 和 [all.csv](../all.csv) 裡，也在 [hproxy.com 的即時清單](https://hproxy.com/free-proxy-list) 上，那裡每一列都可以依國家、協定、匿名等級和上線率篩選。

## 數據告訴我們免費代理是什麼樣的

引擎保存著它見過的每一個代理的歷史，所以關於免費代理的常見說法可以被測量而不是猜測。2026-09-05 對代理池的唯讀查詢：763,409 個代理，115,078,758 次驗證檢測。

- **一個免費代理大約能活六天。** 在已死亡的 691,179 個代理中，壽命中位數為 144.5 小時。22.6% 在第一個小時內就死了，17% 撐過了一個月以上。
- **上線的代理回應不到一半的檢測。** 上線集合中的代理只通過了自身驗證檢測的 45.5%。在曾追蹤過的 765,494 個代理中（2026-09-06），有 667 個回應了 90% 或以上的檢測；它們列在 [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list)。
- **網路上的免費清單其實是同一個池子。** 平均每個上線代理出現在我們抓取的 17.9 個來源上，94.7% 出現在不止一個來源上。從多份清單複製，得到的只是同樣的代理和不同的日期。

實際使用建議：把免費代理用於公開頁面、測試和地區檢查，設定較短的逾時，失敗就換下一行重試。任何涉及登入、付款或帶有機器人偵測的目標，都需要一個穩定上線且不與全網共享的代理；參見 [當免費代理不夠用時](#當免費代理不夠用時)。

## 常見問題

**這份清單裡有多少免費代理？**

**支援哪些協定？**
HTTP、HTTPS、SOCKS4 和 SOCKS5。每個代理都標註它實際回應的協定，而不是它被列出時所標的協定。

**清單多久更新一次？**
每隔幾分鐘從來源抓取候選代理並全天候重新測試。本儲存庫每天更新多次，[hproxy.com 上的即時清單](https://hproxy.com/free-proxy-list) 在幾分鐘內就會顯示結果。

**這些代理是匿名的嗎？**
每個代理根據目標能否看到你的真實 IP 被評為透明、匿名或高匿。在 `all.json` 或 `all.csv` 中依 `anonymity` 欄位篩選，或直接使用 `elite.txt`。

**如何在 Python 中使用代理？**
見上方的 [在你的程式碼中使用](#在你的程式碼中使用)。拉取 `all.txt`，選一行，作為 `http` 和 `https` 代理傳給 `requests`。設定逾時，失敗就換下一行，因為免費代理回應不到一半的檢測。

**需要 API 金鑰或帳號嗎？**
不需要。這裡的原始檔案和 [hproxy.com 上的免費 API](https://hproxy.com/docs/free-proxy-list) 都無需註冊、無需金鑰。

**AI 助理或代理程式能用這份清單嗎？**
能。MCP 伺服器、無金鑰 API 和 llms.txt 頁面就是為此而設的；參見 [在 AI 助理中使用](#在-ai-助理中使用)。

**免費代理安全嗎？**
把它們當作公開且不可信的。用於抓取公開頁面、測試和地區檢查沒有問題。永遠不要透過公開代理傳送密碼、工作階段或付款資料：營運它的人可以讀到任何沒有端對端加密的內容。

**這份清單和其他免費代理清單有什麼不同？**
這裡的每個代理都全天候重新測試並帶有測量資料，而且清單由其他清單使用的同樣公開來源建立，所以一個檔案就能取代一堆清單。背後的歷史資料也一併公開，參見 [數據告訴我們免費代理是什麼樣的](#數據告訴我們免費代理是什麼樣的)。
