## ஒவ்வொரு வரிசையும் உங்களுக்குச் சொல்வது

பெரும்பாலான இலவச ப்ராக்ஸி பட்டியல்கள் வெறும் `ip:port` ஐ மட்டுமே தருகின்றன. இங்கே ஒவ்வொரு வரிசையும் ப்ராக்ஸி ஒரு கோரிக்கைக்குத் தகுதியானதா என்பதைத் தீர்மானிக்கும் அளவீடுகளையும் கொண்டுள்ளது:

| புலம் | அர்த்தம் |
|-------|-------------------|
| `protocols` | HTTP, HTTPS, SOCKS4 மற்றும் SOCKS5 இல் உண்மையில் பதிலளித்த நெறிமுறைகள் |
| `anonymity` | வெளிப்படை, அநாமதேயம் அல்லது elite: இலக்கு உங்கள் உண்மையான IP ஐப் பார்க்க முடியுமா |
| `country` / `city` | வெளியேறும் இடம் எங்கே உள்ளது |
| `latency_ms` | கடைசிச் சோதனையில் அளந்த பதில் நேரம் |
| `uptime_24h` / `uptime_7d` | எத்தனை முறை பதிலளித்தது; ஒருமுறை இயங்கிய ப்ராக்ஸி தொடர்ந்து இயங்கும் ப்ராக்ஸி போலத் தோன்றாமல் இருக்க |

இவை அனைத்தும் [all.json](../all.json) மற்றும் [all.csv](../all.csv) இலும், ஒவ்வொரு வரிசையையும் நாடு, நெறிமுறை, அநாமதேயம் மற்றும் அப்டைம் அடிப்படையில் வடிகட்டக்கூடிய [hproxy.com இல் உள்ள நேரடிப் பட்டியலிலும்](https://hproxy.com/free-proxy-list) உள்ளன.

## AI உதவியாளரிலிருந்து பயன்படுத்துங்கள்

இதே பட்டியல் AI உதவியாளர்களுக்கும் முகவர்களுக்கும் திறந்துள்ளது. HProxy அதே சாவியில்லா API மீது `proxy_list`, `proxy_check` மற்றும் `ip_lookup` ஆகிய மூன்று கருவிகளுடன் ஒரு MCP சேவையகத்தை இயக்குகிறது; Claude Code, Claude Desktop, Cursor மற்றும் Windsurf க்கான அமைப்பு [hproxy.com/tools/ai](https://hproxy.com/tools/ai) இல் உள்ளது. API [hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list) இல் ஆவணப்படுத்தப்பட்டுள்ளது, முழு இலவச API யும் உதவியாளர்களுக்காக எழுதப்பட்ட ஒரே markdown பக்கத்தில் அடங்கும்: [hproxy.com/llms/free-proxy.txt](https://hproxy.com/llms/free-proxy.txt).

உதவியாளருக்கான முழு வழிமுறைகள்: இயங்கும் அனைத்து ப்ராக்ஸிகளுக்கும் `https://hproxy.com/api/proxy-list?format=json` ஐப் பெறுங்கள், வடிகட்ட `protocol=socks5`, `country=US`, `anonymity=elite` அல்லது `min_uptime_pct=90` ஐச் சேருங்கள். சாவி இல்லை, பதிவு இல்லை, CORS திறந்தது. எந்த ப்ராக்ஸியையும் `https://hproxy.com/api/proxy-check?proxy=ip:port` மூலம் சரிபாருங்கள். இவை பொது இலவச ப்ராக்ஸிகள்: எந்த நேரத்திலும் பாதிக்கும் குறைவானவையே பதிலளிக்கும் என எதிர்பாருங்கள், குறுகிய timeout வைத்து அடுத்ததற்குச் செல்லுங்கள்.

இந்தப் பட்டியலை உங்கள் சொந்த மென்பொருளில் இலவசமாகவும் அனுமதி கேட்காமலும் இணைக்கலாம். ஏதேனும் வேலை செய்யவில்லை என்றால், [hproxy.com/contact](https://hproxy.com/contact) இல் ஆதரவு நாள் முழுவதும் கிடைக்கும்.

## இலவச ப்ராக்ஸிகள் பற்றி எண்கள் சொல்வது

இயந்திரம் பார்த்த ஒவ்வொரு ப்ராக்ஸியின் வரலாற்றையும் வைத்திருக்கிறது, எனவே இலவச ப்ராக்ஸிகள் பற்றிய வழக்கமான கூற்றுகளை யூகிப்பதற்குப் பதிலாக அளக்கலாம். 2026-09-05 அன்று தொகுப்பின் மீது படிக்க மட்டும் வினவல்: 763,409 ப்ராக்ஸிகள் மற்றும் 115,078,758 சரிபார்ப்புச் சோதனைகள்.

- **ஒரு இலவச ப்ராக்ஸி சுமார் ஆறு நாட்கள் வாழ்கிறது.** இறந்த 691,179 ப்ராக்ஸிகளின் இடைநிலை ஆயுள்: 144.5 மணி நேரம். 22.6 சதவீதம் முதல் மணி நேரத்திலேயே இறந்தன, 17 சதவீதம் ஒரு மாதத்திற்கும் மேல் நீடித்தன.
- **இயங்கும் ஒன்று அதன் சோதனைகளில் பாதிக்கும் குறைவானவற்றுக்கே பதிலளிக்கிறது.** இயங்கும் தொகுப்பில் உள்ள ஒரு ப்ராக்ஸி அதன் சொந்தச் சரிபார்ப்புச் சோதனைகளில் 45.5 சதவீதத்தில் தேர்ச்சி பெற்றது. இதுவரை கண்காணிக்கப்பட்ட 765,494 ப்ராக்ஸிகளில் (2026-09-06), 667 அவற்றின் சோதனைகளில் 90 சதவீதம் அல்லது அதற்கு மேல் பதிலளித்தன; அவை [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) இல் பட்டியலிடப்பட்டுள்ளன.
- **இணையத்தில் உள்ள இலவசப் பட்டியல்கள் ஒரே தொகுப்பு.** சராசரி இயங்கும் ப்ராக்ஸி நாங்கள் சேகரிக்கும் மூலங்களில் 17.9 இல் தோன்றுகிறது, 94.7 சதவீதம் ஒன்றுக்கு மேற்பட்டவற்றில் தோன்றுகின்றன. பல பட்டியல்களிலிருந்து நகலெடுத்தால் அதே ப்ராக்ஸிகள் வெவ்வேறு தேதிகளுடன் கிடைக்கும்.

நடைமுறையில்: இலவச ப்ராக்ஸிகளைப் பொதுப் பக்கங்கள், சோதனைகள் மற்றும் இருப்பிடச் சரிபார்ப்புகளுக்குக் குறுகிய timeout மற்றும் அடுத்த வரியில் மறுமுயற்சியுடன் பயன்படுத்துங்கள். உள்நுழைவு, கட்டணம் அல்லது bot கண்டறிதல் உள்ள இலக்கு எதுவாக இருந்தாலும், தொடர்ந்து இயங்கும் மற்றும் முழு இணையத்துடனும் பகிரப்படாத ப்ராக்ஸி தேவை; பார்க்க: [இலவச ப்ராக்ஸி போதாதபோது](#இலவச-பராகஸி-போதாதபோது).

## அடிக்கடி கேட்கப்படும் கேள்விகள்

**இந்தப் பட்டியலில் எத்தனை இலவச ப்ராக்ஸிகள் உள்ளன?**
இதுவரை 770,610 கண்காணிக்கப்பட்டுள்ளன. 5,560 இந்த நிமிடத்தில் இயங்குகின்றன, 31,614 கடந்த 48 மணி நேரத்தில் பதிலளித்தன, வெளியிடப்பட்ட கோப்புகளில் சரியாக அவையே உள்ளன.

**எந்த நெறிமுறைகள் ஆதரிக்கப்படுகின்றன?**
HTTP, HTTPS, SOCKS4 மற்றும் SOCKS5. ஒவ்வொரு ப்ராக்ஸியும் பட்டியலிடப்பட்ட நெறிமுறைகளுடன் அல்ல, உண்மையில் பதிலளித்த நெறிமுறைகளுடன் லேபிளிடப்பட்டுள்ளது.

**பட்டியல் எவ்வளவு அடிக்கடி புதுப்பிக்கப்படுகிறது?**
வேட்பாளர்கள் சில நிமிடங்களுக்கு ஒருமுறை மூலங்களிலிருந்து சேகரிக்கப்பட்டு நாள் முழுவதும் மீண்டும் சோதிக்கப்படுகிறார்கள். இந்தக் களஞ்சியம் நாளொன்றுக்குப் பல முறை புதுப்பிக்கப்படுகிறது, [hproxy.com இல் உள்ள நேரடிப் பட்டியல்](https://hproxy.com/free-proxy-list) சில நிமிடங்களில் முடிவுகளைக் காட்டுகிறது.

**ப்ராக்ஸிகள் அநாமதேயமானவையா?**
இலக்கு உங்கள் உண்மையான IP ஐப் பார்க்கிறதா என்பதன் அடிப்படையில் ஒவ்வொன்றும் வெளிப்படை, அநாமதேயம் அல்லது elite எனத் தரப்படுத்தப்படுகிறது. `all.json` அல்லது `all.csv` இல் `anonymity` புலத்தால் வடிகட்டுங்கள், அல்லது `elite.txt` ஐ எடுங்கள்.

**Python இல் ப்ராக்ஸியை எப்படிப் பயன்படுத்துவது?**
மேலே [உங்கள் குறியீட்டில் பயன்படுத்துங்கள்](#உஙகள-குறியீடடில-பயனபடுததுஙகள) ஐப் பாருங்கள். `all.txt` ஐப் பெற்று, ஒரு வரியைத் தேர்ந்தெடுத்து, `requests` க்கு `http` மற்றும் `https` ப்ராக்ஸியாகக் கொடுங்கள். timeout வைத்து, தோல்வியில் அடுத்த வரிக்குச் செல்லுங்கள், ஏனெனில் இலவச ப்ராக்ஸி அதன் சோதனைகளில் பாதிக்கும் குறைவானவற்றுக்கே பதிலளிக்கிறது.

**எனக்கு API சாவி அல்லது கணக்கு தேவையா?**
இல்லை. இங்குள்ள மூலக் கோப்புகளுக்கும் [hproxy.com இல் உள்ள இலவச API க்கும்](https://hproxy.com/docs/free-proxy-list) பதிவோ சாவியோ தேவையில்லை.

**AI உதவியாளர் அல்லது முகவர் இந்தப் பட்டியலைப் பயன்படுத்த முடியுமா?**
ஆம். MCP சேவையகம், சாவியில்லா API மற்றும் llms.txt பக்கங்கள் அதற்காகவே உருவாக்கப்பட்டவை; பார்க்க: [AI உதவியாளரிலிருந்து பயன்படுத்துங்கள்](#ai-உதவியாளரிலிருநது-பயனபடுததுஙகள).

**இலவச ப்ராக்ஸிகள் பயன்படுத்தப் பாதுகாப்பானவையா?**
அவற்றைப் பொதுவானவை மற்றும் நம்பத்தகாதவை என்று கருதுங்கள். பொதுப் பக்கங்களைச் சேகரிக்க, சோதிக்க மற்றும் இருப்பிடச் சரிபார்ப்புக்கு அவை பொருத்தமானவை. கடவுச்சொற்கள், அமர்வுகள் அல்லது கட்டணத் தரவை ஒருபோதும் பொது ப்ராக்ஸி வழியாக அனுப்பாதீர்கள்: அதை இயக்குபவர் முனையிலிருந்து முனை வரை குறியாக்கம் செய்யப்படாத எதையும் படிக்க முடியும்.

**இந்தப் பட்டியல் மற்ற இலவச ப்ராக்ஸி பட்டியல்களிலிருந்து எப்படி வேறுபடுகிறது?**
இங்குள்ள ஒவ்வொரு ப்ராக்ஸியும் நாள் முழுவதும் மீண்டும் சோதிக்கப்பட்டு அதன் அளவீடுகளைக் கொண்டுள்ளது, மற்ற பட்டியல்கள் பயன்படுத்தும் அதே பொது மூலங்களிலிருந்து இந்தப் பட்டியல் கட்டப்பட்டுள்ளது, எனவே ஒரே கோப்பு முழுத் தொகுப்பையும் மாற்றுகிறது. அதன் பின்னணி வரலாறும் வெளியிடப்பட்டுள்ளது, பார்க்க: [இலவச ப்ராக்ஸிகள் பற்றி எண்கள் சொல்வது](#இலவச-பராகஸிகள-பறறி-எணகள-சொலவது).

## நாங்கள் ஒருங்கிணைக்கும் மூலங்கள்

இயந்திரம் 100க்கும் மேற்பட்ட பொது ப்ராக்ஸி மூலங்களிலிருந்து சேகரித்து, நகல்களை நீக்கி, அனைத்தையும் சோதித்து, அளவீடுகளை ஒரே இடத்தில் இணைக்கிறது. டஜன் கணக்கான பொதுக் களஞ்சியங்களையும் ப்ராக்ஸி தளங்களையும் நீங்களே சேகரித்து ஒப்பிடுவதற்குப் பதிலாக, அவற்றின் சரிபார்க்கப்பட்ட, நகலற்ற ஒன்றிணைப்பை நாள் முழுவதும் புதுப்பிக்கப்பட்ட நிலையில் பெறுகிறீர்கள்.

நாங்கள் சேகரிக்க வேண்டிய பொது ப்ராக்ஸி மூலம் ஒன்று தெரியுமா? [ஒரு issue திறங்கள்](https://github.com/hproxy-com/free-proxy-list/issues), அதைச் சேர்ப்பதைப் பரிசீலிப்போம்.

## இது எப்படி வேலை செய்கிறது

1. **சேகரிப்பு**: சில நிமிடங்களுக்கு ஒருமுறை 100க்கும் மேற்பட்ட பொது மூலங்களிலிருந்து வேட்பாளர்கள்.
2. **சரிபார்ப்பு**: ஒவ்வொரு ப்ராக்ஸியும் HTTP, HTTPS, SOCKS4 மற்றும் SOCKS5 வழியாக, நாள் முழுவதும்.
3. **அளவீடு**: இயங்கும் ஒவ்வொரு ப்ராக்ஸியின் நாடு, அநாமதேய நிலை, தாமதம், அப்டைம்.
4. **வெளியீடு**: முடிவு இங்கே நாளொன்றுக்குப் பல முறை, [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) இல் சில நிமிடங்களில்.

## இலவச ப்ராக்ஸி போதாதபோது

இலவச ப்ராக்ஸி அதே பட்டியலைக் கண்ட அனைவருடனும் பகிரப்படுகிறது, எனவே மக்கள் உண்மையில் விரும்பும் இலக்குகள் வழக்கமாக உங்களுக்கு முன்பே அதைப் பார்த்திருக்கும். தொடர்ந்து இயங்கும், அமர்வைத் தக்கவைக்கும், முழு இணையத்துடனும் பகிரப்படாத ப்ராக்ஸி வேலைக்குத் தேவைப்படும்போது, [HProxy](https://hproxy.com) குடியிருப்பு, ISP, மொபைல் மற்றும் datacenter ப்ராக்ஸிகளை ஜிகாபைட் அடிப்படையில், GB க்கு $0.44 இலிருந்து விற்கிறது. அதே தளத்தில் ப்ராக்ஸி சரிபார்ப்பானும் நேரடிப் பட்டியலும் இலவசமாகவே இருக்கும்.
