## Was jede Zeile verrät

Die meisten kostenlosen Proxy-Listen liefern ein nacktes `ip:port`. Hier trägt jede Zeile zusätzlich die Messwerte, die entscheiden, ob der Proxy eine Anfrage wert ist:

| Feld | Was es bedeutet |
|-------|-------------------|
| `protocols` | Die Protokolle, auf denen er tatsächlich geantwortet hat, aus HTTP, HTTPS, SOCKS4 und SOCKS5 |
| `anonymity` | Transparent, anonym oder elite: ob die Zielseite Ihre echte IP sehen kann |
| `country` / `city` | Wo der Ausgang sitzt |
| `latency_ms` | Gemessene Antwortzeit bei der letzten Prüfung |
| `uptime_24h` / `uptime_7d` | Wie oft er geantwortet hat, damit ein Proxy, der einmal lief, nicht aussieht wie einer, der läuft |

All das steht in [all.json](../all.json) und [all.csv](../all.csv) und in der [Live-Liste auf hproxy.com](https://hproxy.com/free-proxy-list), wo sich jede Zeile nach Land, Protokoll, Anonymität und Verfügbarkeit filtern lässt.

## Im eigenen Code verwenden

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl:**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

**Node.js:**

```js
const list = await fetch("https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt")
  .then(r => r.text());
const proxies = list.trim().split("\n");
```

## Aus einem KI-Assistenten verwenden

Dieselbe Liste steht KI-Assistenten und Agenten offen. HProxy betreibt einen MCP-Server mit drei Werkzeugen, `proxy_list`, `proxy_check` und `ip_lookup`, auf derselben schlüssellosen API, und die Einrichtung für Claude Code, Claude Desktop, Cursor und Windsurf steht unter [hproxy.com/tools/ai](https://hproxy.com/tools/ai). Die API ist unter [hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list) dokumentiert, und die gesamte kostenlose API passt auf eine für Assistenten geschriebene Markdown-Seite, [hproxy.com/llms/free-proxy.txt](https://hproxy.com/llms/free-proxy.txt).

Anweisungen für einen Assistenten, vollständig: `https://hproxy.com/api/proxy-list?format=json` abrufen, um jeden erreichbaren Proxy zu erhalten, und `protocol=socks5`, `country=US`, `anonymity=elite` oder `min_uptime_pct=90` zum Filtern anhängen. Kein Schlüssel, keine Anmeldung, CORS offen. Jeden Proxy mit `https://hproxy.com/api/proxy-check?proxy=ip:port` prüfen. Es sind öffentliche kostenlose Proxys: Rechnen Sie damit, dass zu jedem Zeitpunkt weniger als die Hälfte antwortet, setzen Sie einen kurzen Timeout und gehen Sie zum nächsten über.

Sie dürfen die Liste kostenlos und ohne Rückfrage in Ihre eigene Software einbauen. Wenn etwas nicht funktioniert, ist der Support rund um die Uhr unter [hproxy.com/contact](https://hproxy.com/contact) besetzt.

## Was die Zahlen über kostenlose Proxys sagen

Die Engine bewahrt die Geschichte jedes Proxys, den sie je gesehen hat, deshalb lassen sich die üblichen Behauptungen über kostenlose Proxys messen statt raten. Lesende Abfrage über den Pool am 2026-09-05: 763.409 Proxys und 115.078.758 Prüfungen.

- **Ein kostenloser Proxy lebt etwa sechs Tage.** Mediane Lebensdauer über die 691.179 Proxys, die gestorben sind: 144,5 Stunden. 22,6 Prozent waren innerhalb der ersten Stunde tot, und 17 Prozent hielten länger als einen Monat.
- **Ein erreichbarer Proxy beantwortet weniger als die Hälfte seiner Prüfungen.** Ein Proxy aus der erreichbaren Menge hat 45,5 Prozent seiner eigenen Prüfungen bestanden. Von den 765.494 je erfassten Proxys (2026-09-06) haben 667 auf 90 Prozent ihrer Prüfungen oder mehr geantwortet; sie stehen unter [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list).
- **Die kostenlosen Listen im Internet sind ein einziger Pool.** Der durchschnittliche erreichbare Proxy taucht in 17,9 der Quellen auf, aus denen wir ziehen, und 94,7 Prozent tauchen in mehr als einer auf. Wer aus mehreren Listen kopiert, bekommt dieselben Proxys mit anderen Daten.

In der Praxis: Kostenlose Proxys für öffentliche Seiten, Tests und Standortprüfungen verwenden, mit kurzem Timeout und einem neuen Versuch in der nächsten Zeile. Alles mit Login, Zahlung oder einem Ziel mit Bot-Erkennung braucht einen Proxy, der läuft und nicht mit dem ganzen Internet geteilt wird; siehe [Wenn ein kostenloser Proxy nicht reicht](#wenn-ein-kostenloser-proxy-nicht-reicht).

## FAQ

**Wie viele kostenlose Proxys enthält diese Liste?**
768,073 wurden bisher erfasst. 4,088 sind in dieser Minute erreichbar und 60,837 haben in den letzten 48 Stunden geantwortet, und die veröffentlichten Dateien enthalten genau diese.

**Welche Protokolle werden unterstützt?**
HTTP, HTTPS, SOCKS4 und SOCKS5. Jeder Proxy trägt die Protokolle, auf denen er tatsächlich geantwortet hat, nicht die, unter denen er gelistet war.

**Wie oft wird die Liste aktualisiert?**
Kandidaten werden alle paar Minuten aus den Quellen geholt und rund um die Uhr erneut getestet. Dieses Repository wird mehrmals täglich aktualisiert, und die [Live-Liste auf hproxy.com](https://hproxy.com/free-proxy-list) zeigt Ergebnisse innerhalb von Minuten.

**Sind die Proxys anonym?**
Jeder wird als transparent, anonym oder elite eingestuft, je nachdem, ob die Zielseite Ihre echte IP sieht. Filtern Sie nach dem Feld `anonymity` in `all.json` oder `all.csv`, oder nehmen Sie `elite.txt`.

**Wie verwende ich einen Proxy in Python?**
Siehe [Im eigenen Code verwenden](#im-eigenen-code-verwenden) oben. `all.txt` abrufen, eine Zeile wählen und sie `requests` als `http`- und `https`-Proxy übergeben. Einen Timeout setzen und bei einem Fehler zur nächsten Zeile gehen, denn ein kostenloser Proxy beantwortet weniger als die Hälfte seiner Prüfungen.

**Brauche ich einen API-Schlüssel oder ein Konto?**
Nein. Weder die Rohdateien hier noch die [kostenlose API auf hproxy.com](https://hproxy.com/docs/free-proxy-list) brauchen eine Anmeldung oder einen Schlüssel.

**Kann ein KI-Assistent oder Agent diese Liste verwenden?**
Ja. Der MCP-Server, die schlüssellose API und die llms.txt-Seiten sind genau dafür gemacht; siehe [Aus einem KI-Assistenten verwenden](#aus-einem-ki-assistenten-verwenden).

**Sind kostenlose Proxys sicher?**
Behandeln Sie sie als öffentlich und nicht vertrauenswürdig. Für das Abrufen öffentlicher Seiten, Tests und Standortprüfungen sind sie in Ordnung. Schicken Sie niemals Passwörter, Sitzungen oder Zahlungsdaten durch einen öffentlichen Proxy: Wer ihn betreibt, kann alles lesen, was nicht Ende-zu-Ende verschlüsselt ist.

**Worin unterscheidet sich diese Liste von anderen kostenlosen Proxy-Listen?**
Jeder Proxy hier wird rund um die Uhr erneut getestet und trägt seine Messwerte, und die Liste ist aus denselben öffentlichen Quellen gebaut, die die anderen Listen nutzen, sodass eine Datei die ganze Sammlung ersetzt. Die Geschichte dahinter ist ebenfalls veröffentlicht, siehe [Was die Zahlen über kostenlose Proxys sagen](#was-die-zahlen-über-kostenlose-proxys-sagen).

## Wenn ein kostenloser Proxy nicht reicht

Einen kostenlosen Proxy teilen sich alle, die dieselbe Liste gefunden haben, deshalb haben die Ziele, die Menschen wirklich interessieren, ihn meist schon vor Ihnen gesehen. Wenn die Aufgabe einen Proxy braucht, der läuft, eine Sitzung hält und nicht mit dem ganzen Internet geteilt wurde, verkauft [HProxy](https://hproxy.com) Residential-, ISP-, Mobil- und Rechenzentrums-Proxys nach Gigabyte, ab $0.44 pro GB. Der Proxy-Checker und die Live-Liste auf derselben Seite bleiben kostenlos.
