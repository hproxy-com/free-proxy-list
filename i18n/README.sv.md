## Vad varje rad berättar

De flesta gratis proxylistor ger dig ett naket `ip:port`. Här bär varje rad också de mätningar som avgör om proxyn är värd en förfrågan:

| Fält | Vad det säger |
|-------|-------------------|
| `protocols` | De protokoll den faktiskt svarade på, av HTTP, HTTPS, SOCKS4 och SOCKS5 |
| `anonymity` | Transparent, anonym eller elite: om målet kan se din riktiga IP |
| `country` / `city` | Var utgången sitter |
| `latency_ms` | Uppmätt svarstid vid senaste kontrollen |
| `uptime_24h` / `uptime_7d` | Hur ofta den svarade, så att en proxy som var uppe en gång inte ser ut som en som håller sig uppe |

Allt det finns i [all.json](../all.json) och [all.csv](../all.csv), och i [livelistan på hproxy.com](https://hproxy.com/free-proxy-list), där varje rad kan filtreras på land, protokoll, anonymitet och upptid.

## Använd den i din kod

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl:**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

**Node.js:**

```js
const list = await fetch("https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt")
  .then(r => r.text());
const proxies = list.trim().split("\n");
```

## Vad siffrorna säger om gratisproxyer

Motorn sparar historiken för varje proxy den någonsin sett, så de vanliga påståendena om gratisproxyer kan mätas i stället för att gissas. Läsfråga mot poolen 2026-09-05: 763 409 proxyer och 115 078 758 verifieringskontroller.

- **En gratisproxy lever ungefär sex dagar.** Medianlivslängd över de 691 179 proxyer som dött: 144,5 timmar. 22,6 procent var döda inom sin första timme, och 17 procent höll i mer än en månad.
- **En uppe proxy svarar på färre än hälften av sina kontroller.** En proxy i den uppe mängden klarade 45,5 procent av sina egna verifieringskontroller. Av de 765 494 proxyer som någonsin följts (2026-09-06) har 667 svarat på 90 procent av sina kontroller eller mer; de listas på [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list).
- **Gratislistorna på internet är en enda pool.** Den genomsnittliga uppe proxyn förekommer i 17,9 av de källor vi hämtar från, och 94,7 procent förekommer i fler än en. Att kopiera från flera listor ger dig samma proxyer med olika datum.

I praktiken: använd gratisproxyer för offentliga sidor, tester och platskontroller, med kort timeout och ett nytt försök på nästa rad.
