# ఉచిత ప్రాక్సీ జాబితా, రోజంతా ధృవీకరించబడుతుంది

<p align="center"><b>ఈ క్షణంలో 6,987 ఉచిత ప్రాక్సీలు పనిచేస్తున్నాయి, గత 48 గంటల్లో 34,220 పనిచేశాయి, ప్రతి ఒక్కటీ పరీక్షించి లేబుల్ చేయబడింది.</b></p>
<p align="center"><sub>HTTP, HTTPS, SOCKS4 మరియు SOCKS5 &middot; ప్రతి వరుసలో దేశం, అనామకత్వం, జాప్యం మరియు అప్‌టైమ్ &middot; నవీకరణ 10.09.2026</sub></p>

ఇది [HProxy](https://hproxy.com/free-proxy-list) ప్రచురించే ఉచిత ప్రాక్సీ జాబితా. ఒక ఇంజిన్ ప్రతి కొన్ని నిమిషాలకు 100కు పైగా బహిరంగ మూలాల నుంచి అభ్యర్థులను సేకరించి, ప్రతి దాన్నీ HTTP, HTTPS, SOCKS4 మరియు SOCKS5 ద్వారా పరీక్షించి, స్పందించే ప్రతి ప్రాక్సీ దేశం, అనామకత్వ స్థాయి, జాప్యం మరియు అప్‌టైమ్‌ను నమోదు చేస్తుంది. ఇప్పటివరకు అది **773,599** ప్రాక్సీలను ట్రాక్ చేసింది. **6,987** ఈ నిమిషంలో పనిచేస్తున్నాయి, **34,220** గత 48 గంటల్లో స్పందించాయి, రెండు సెట్లూ ప్రచురించబడతాయి: `live.txt`లో ఇప్పుడు పనిచేస్తున్నవి మాత్రమే ఉంటాయి, `all.txt`లో ఉచిత ప్రాక్సీలు వచ్చిపోయే విస్తృత పూల్ ఉంటుంది. సైన్అప్ లేదు, API కీ లేదు, ఫైళ్లను అవసరమైనన్ని సార్లు తీసుకోవచ్చు.

మీరు డజను రిపోజిటరీలు, సైట్ల నుంచి ప్రాక్సీలు సేకరిస్తూ ఉంటే, ఈ జాబితాలో అవి ఇప్పటికే ఉన్నాయి. అదే బహిరంగ మూలాల నుంచి నిర్మించి, ఆపై పరీక్షించబడింది. చూడండి: [మేము సమీకరించే మూలాలు](#మేము-సమీకరించే-మూలాలు).

## ప్రతి వరుస మీకు ఏం చెబుతుంది

చాలా ఉచిత ప్రాక్సీ జాబితాలు మీకు ఒట్టి `ip:port` ఇస్తాయి. ఇక్కడ ప్రతి వరుసలో ఆ ప్రాక్సీ ఒక అభ్యర్థనకు తగినదో కాదో నిర్ణయించే కొలతలు కూడా ఉంటాయి:

| ఫీల్డ్ | అర్థం |
|-------|-------------------|
| `protocols` | HTTP, HTTPS, SOCKS4 మరియు SOCKS5లలో నిజంగా స్పందించిన ప్రోటోకాల్‌లు |
| `anonymity` | పారదర్శకం, అనామకం లేదా elite: లక్ష్యం మీ అసలు IPని చూడగలదా |
| `country` / `city` | నిష్క్రమణ ఎక్కడ ఉంది |
| `latency_ms` | చివరి తనిఖీలో కొలిచిన స్పందన సమయం |
| `uptime_24h` / `uptime_7d` | ఎంత తరచుగా స్పందించింది; ఒకసారి పనిచేసిన ప్రాక్సీ నిరంతరం పనిచేసే ప్రాక్సీలా కనిపించకుండా |

ఇవన్నీ [all.json](../all.json) మరియు [all.csv](../all.csv)లో, అలాగే ప్రతి వరుసను దేశం, ప్రోటోకాల్, అనామకత్వం మరియు అప్‌టైమ్ ప్రకారం వడపోయగల [hproxy.comలోని లైవ్ జాబితాలో](https://hproxy.com/free-proxy-list) ఉన్నాయి.

## మీ కోడ్‌లో వాడండి

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl:**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

**Node.js:**

```js
const list = await fetch("https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt")
  .then(r => r.text());
const proxies = list.trim().split("\n");
```

ప్రతి ఫైల్ రిపోజిటరీతో పాటు రిఫ్రెష్ అయ్యే ముడి endpoint. jsDelivr మిర్రర్ అవే ఫైళ్లను రేట్ లిమిట్ లేకుండా అందిస్తుంది:

```bash
curl https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt            # పనిచేసే ప్రతి ప్రాక్సీ, ప్రతి పంక్తికి ఒక ip:port
curl https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/by-country/US.txt  # ఒక దేశం
curl https://cdn.jsdelivr.net/gh/hproxy-com/free-proxy-list@main/all.json           # పూర్తి వివరాలు, CDN ద్వారా
```

ఏదీ clone చేయకుండా దేశం, ప్రోటోకాల్ మరియు అప్‌టైమ్ ఫిల్టర్లు కావాలంటే, **[hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list)**లో డాక్యుమెంట్ చేసిన ఉచిత రియల్-టైమ్ APIని వాడండి, లేదా ప్రతి ప్రాక్సీకి సొంత పేజీ ఉన్న **[hproxy.comలోని లైవ్ జాబితాను](https://hproxy.com/free-proxy-list)** తెరవండి.

## AI అసిస్టెంట్ నుంచి వాడండి

ఇదే జాబితా AI అసిస్టెంట్లకు, ఏజెంట్లకు కూడా అందుబాటులో ఉంది. HProxy అదే కీ-లేని API పైన `proxy_list`, `proxy_check` మరియు `ip_lookup` అనే మూడు సాధనాలతో MCP సర్వర్‌ను నడుపుతుంది; Claude Code, Claude Desktop, Cursor మరియు Windsurf కోసం సెటప్ [hproxy.com/tools/ai](https://hproxy.com/tools/ai)లో ఉంది. API [hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list)లో డాక్యుమెంట్ చేయబడింది, పూర్తి ఉచిత API అసిస్టెంట్ల కోసం రాసిన ఒకే markdown పేజీలో ఇమిడిపోతుంది: [hproxy.com/llms/free-proxy.txt](https://hproxy.com/llms/free-proxy.txt).

అసిస్టెంట్ కోసం పూర్తి సూచనలు: పనిచేస్తున్న ప్రతి ప్రాక్సీ కోసం `https://hproxy.com/api/proxy-list?format=json` తీసుకోండి, వడపోయడానికి `protocol=socks5`, `country=US`, `anonymity=elite` లేదా `min_uptime_pct=90` జోడించండి. కీ లేదు, సైన్అప్ లేదు, CORS తెరిచి ఉంది. ఏ ప్రాక్సీనైనా `https://hproxy.com/api/proxy-check?proxy=ip:port`తో తనిఖీ చేయండి. ఇవి బహిరంగ ఉచిత ప్రాక్సీలు: ఏ క్షణంలోనైనా సగం కంటే తక్కువే స్పందిస్తాయని ఊహించండి, చిన్న timeout పెట్టి తర్వాతిదానికి వెళ్లండి.

ఈ జాబితాను మీ సొంత సాఫ్ట్‌వేర్‌లో ఉచితంగా, అడగకుండా చేర్చుకోవచ్చు. ఏదైనా పనిచేయకపోతే, [hproxy.com/contact](https://hproxy.com/contact)లో మద్దతు రోజంతా అందుబాటులో ఉంటుంది.

## ఉచిత ప్రాక్సీల గురించి సంఖ్యలు ఏం చెబుతున్నాయి

ఇంజిన్ తాను చూసిన ప్రతి ప్రాక్సీ చరిత్రను భద్రపరుస్తుంది, కాబట్టి ఉచిత ప్రాక్సీల గురించిన సాధారణ వాదనలను ఊహించడానికి బదులు కొలవవచ్చు. 2026-09-05న పూల్‌పై చదవడానికి-మాత్రమే క్వెరీ: 763,409 ప్రాక్సీలు మరియు 115,078,758 ధృవీకరణ తనిఖీలు.

- **ఒక ఉచిత ప్రాక్సీ దాదాపు ఆరు రోజులు జీవిస్తుంది.** చనిపోయిన 691,179 ప్రాక్సీలలో మధ్యస్థ జీవితకాలం: 144.5 గంటలు. 22.6 శాతం మొదటి గంటలోనే చనిపోయాయి, 17 శాతం నెలకు పైగా నిలిచాయి.
- **పనిచేసే ప్రాక్సీ తన తనిఖీలలో సగం కంటే తక్కువకే స్పందిస్తుంది.** పనిచేసే సెట్‌లోని ఒక ప్రాక్సీ తన సొంత ధృవీకరణ తనిఖీలలో 45.5 శాతం ఉత్తీర్ణమైంది. ఇప్పటివరకు ట్రాక్ చేసిన 765,494 ప్రాక్సీలలో (2026-09-06), 667 తమ తనిఖీలలో 90 శాతం లేదా అంతకంటే ఎక్కువకు స్పందించాయి; అవి [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list)లో జాబితా చేయబడ్డాయి.
- **ఇంటర్నెట్‌లోని ఉచిత జాబితాలు ఒకే పూల్.** సగటు పనిచేసే ప్రాక్సీ మేము సేకరించే మూలాలలో 17.9లో కనిపిస్తుంది, 94.7 శాతం ఒకటి కంటే ఎక్కువ మూలాలలో కనిపిస్తాయి. అనేక జాబితాల నుంచి కాపీ చేస్తే అవే ప్రాక్సీలు వేర్వేరు తేదీలతో దొరుకుతాయి.

ఆచరణలో: ఉచిత ప్రాక్సీలను బహిరంగ పేజీలు, పరీక్షలు మరియు స్థాన తనిఖీల కోసం చిన్న timeout మరియు తర్వాతి పంక్తిలో మళ్లీ ప్రయత్నంతో వాడండి. లాగిన్, చెల్లింపు లేదా బాట్ గుర్తింపు ఉన్న లక్ష్యం ఏదైనా సరే, నిరంతరం పనిచేసే మరియు ఇంటర్నెట్ మొత్తంతో పంచుకోని ప్రాక్సీ కావాలి; చూడండి: [ఉచిత ప్రాక్సీ సరిపోనప్పుడు](#ఉచిత-పరాకసీ-సరిపోనపపుడు).

## తరచుగా అడిగే ప్రశ్నలు

**ఈ జాబితాలో ఎన్ని ఉచిత ప్రాక్సీలు ఉన్నాయి?**
ఇప్పటివరకు 773,599 ట్రాక్ చేయబడ్డాయి. 6,987 ఈ నిమిషంలో పనిచేస్తున్నాయి, 34,220 గత 48 గంటల్లో స్పందించాయి, ప్రచురించిన ఫైళ్లలో సరిగ్గా అవే ఉన్నాయి.

**ఏ ప్రోటోకాల్‌లకు మద్దతు ఉంది?**
HTTP, HTTPS, SOCKS4 మరియు SOCKS5. ప్రతి ప్రాక్సీ జాబితాలో పెట్టిన ప్రోటోకాల్‌లతో కాదు, నిజంగా స్పందించిన ప్రోటోకాల్‌లతో లేబుల్ చేయబడింది.

**జాబితా ఎంత తరచుగా నవీకరించబడుతుంది?**
అభ్యర్థులు ప్రతి కొన్ని నిమిషాలకు మూలాల నుంచి సేకరించబడి రోజంతా మళ్లీ పరీక్షించబడతారు. ఈ రిపోజిటరీ రోజుకు చాలాసార్లు రిఫ్రెష్ అవుతుంది, [hproxy.comలోని లైవ్ జాబితా](https://hproxy.com/free-proxy-list) నిమిషాల్లో ఫలితాలు చూపుతుంది.

**ప్రాక్సీలు అనామకమైనవా?**
లక్ష్యం మీ అసలు IPని చూస్తుందా అనే దాన్ని బట్టి ప్రతి ఒక్కటీ పారదర్శకం, అనామకం లేదా elite అని గ్రేడ్ చేయబడుతుంది. `all.json` లేదా `all.csv`లో `anonymity` ఫీల్డ్ ద్వారా వడపోయండి, లేదా `elite.txt` తీసుకోండి.

**Pythonలో ప్రాక్సీని ఎలా వాడాలి?**
పైన [మీ కోడ్‌లో వాడండి](#మీ-కోడలో-వాడండి) చూడండి. `all.txt` తీసుకుని, ఒక పంక్తి ఎంచుకుని, దాన్ని `requests`కు `http` మరియు `https` ప్రాక్సీగా ఇవ్వండి. timeout పెట్టి, విఫలమైతే తర్వాతి పంక్తికి వెళ్లండి, ఎందుకంటే ఉచిత ప్రాక్సీ తన తనిఖీలలో సగం కంటే తక్కువకే స్పందిస్తుంది.

**నాకు API కీ లేదా ఖాతా అవసరమా?**
లేదు. ఇక్కడి ముడి ఫైళ్లకు గానీ, [hproxy.comలోని ఉచిత APIకి](https://hproxy.com/docs/free-proxy-list) గానీ సైన్అప్ లేదా కీ అవసరం లేదు.

**AI అసిస్టెంట్ లేదా ఏజెంట్ ఈ జాబితాను వాడగలదా?**
అవును. MCP సర్వర్, కీ-లేని API మరియు llms.txt పేజీలు దాని కోసమే తయారయ్యాయి; చూడండి: [AI అసిస్టెంట్ నుంచి వాడండి](#ai-అసిసటెంట-నుంచి-వాడండి).

**ఉచిత ప్రాక్సీలు వాడటం సురక్షితమేనా?**
వాటిని బహిరంగమైనవిగా, నమ్మదగనివిగా భావించండి. బహిరంగ పేజీలను స్క్రేప్ చేయడానికి, పరీక్షలకు, స్థాన తనిఖీలకు అవి సరిపోతాయి. బహిరంగ ప్రాక్సీ ద్వారా పాస్‌వర్డ్‌లు, సెషన్లు లేదా చెల్లింపు డేటాను ఎప్పుడూ పంపకండి: దాన్ని నడిపేవారు ఎండ్-టు-ఎండ్ ఎన్‌క్రిప్ట్ కాని ప్రతిదాన్నీ చదవగలరు.

**ఈ జాబితా ఇతర ఉచిత ప్రాక్సీ జాబితాల కంటే ఎలా భిన్నం?**
ఇక్కడి ప్రతి ప్రాక్సీ రోజంతా మళ్లీ పరీక్షించబడి తన కొలతలను తీసుకువస్తుంది, ఇతర జాబితాలు వాడే అవే బహిరంగ మూలాల నుంచి ఈ జాబితా నిర్మించబడింది, కాబట్టి ఒకే ఫైల్ మొత్తం సేకరణ స్థానాన్ని తీసుకుంటుంది. దాని వెనుక చరిత్ర కూడా ప్రచురించబడింది, చూడండి: [ఉచిత ప్రాక్సీల గురించి సంఖ్యలు ఏం చెబుతున్నాయి](#ఉచిత-పరాకసీల-గురించి-సంఖయలు-ఏం-చెబుతుననాయి).

## మేము సమీకరించే మూలాలు

ఇంజిన్ 100కు పైగా బహిరంగ ప్రాక్సీ మూలాల నుంచి సేకరించి, నకిలీలను తొలగించి, అన్నింటినీ పరీక్షించి, కొలతలను ఒకే చోట చేరుస్తుంది. డజను బహిరంగ రిపోజిటరీలను, ప్రాక్సీ సైట్లను మీరే స్క్రేప్ చేసి పోల్చుకోవడానికి బదులు, వాటి తనిఖీ చేసిన, నకిలీలు లేని కలయికను రోజంతా రిఫ్రెష్ అయ్యే స్థితిలో పొందుతారు.

మేము సేకరించాల్సిన బహిరంగ ప్రాక్సీ మూలం ఏదైనా తెలుసా? [ఒక issue తెరవండి](https://github.com/hproxy-com/free-proxy-list/issues), దాన్ని జోడించడాన్ని పరిశీలిస్తాము.
