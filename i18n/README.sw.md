## Kila safu inakuambia nini

Orodha nyingi za proksi za bure hukupa `ip:port` tupu. Hapa kila safu pia ina vipimo vinavyoamua kama proksi inastahili ombi:

| Sehemu | Maana yake |
|-------|-------------------|
| `protocols` | Itifaki ilizojibu kweli, kati ya HTTP, HTTPS, SOCKS4 na SOCKS5 |
| `anonymity` | Wazi, isiyojulikana au elite: kama lengo linaweza kuona IP yako halisi |
| `country` / `city` | Mahali pa kutokea palipo |
| `latency_ms` | Muda wa majibu uliopimwa katika ukaguzi wa mwisho |
| `uptime_24h` / `uptime_7d` | Mara ngapi ilijibu, ili proksi iliyofanya kazi mara moja isionekane kama inayoendelea kufanya kazi |

Yote hayo yamo katika [all.json](../all.json) na [all.csv](../all.csv), na kwenye [orodha ya moja kwa moja ya hproxy.com](https://hproxy.com/free-proxy-list), ambapo kila safu inaweza kuchujwa kwa nchi, itifaki, kutokujulikana na muda wa kufanya kazi.

## Itumie katika msimbo wako

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```
