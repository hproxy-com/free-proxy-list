## Lo que dice cada fila

La mayoría de las listas de proxies gratis entregan un simple `ip:port`. Aquí cada fila lleva además las mediciones que deciden si el proxy merece una petición:

| Campo | Lo que indica |
|-------|-------------------|
| `protocols` | Los protocolos en los que realmente respondió, entre HTTP, HTTPS, SOCKS4 y SOCKS5 |
| `anonymity` | Transparente, anónimo o elite: si el destino puede ver su IP real |
| `country` / `city` | Dónde está la salida |
| `latency_ms` | Tiempo de respuesta medido en la última comprobación |
| `uptime_24h` / `uptime_7d` | Con qué frecuencia respondió, para que un proxy que estuvo activo una vez no parezca uno que se mantiene activo |

Todo está en [all.json](../all.json) y [all.csv](../all.csv), y en la [lista en vivo de hproxy.com](https://hproxy.com/free-proxy-list), donde cada fila se puede filtrar por país, protocolo, anonimato y disponibilidad.

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",

```

El motor conserva el historial de cada proxy que ha visto, así que las afirmaciones habituales sobre los proxies gratis se pueden medir en lugar de adivinar. Consulta de solo lectura sobre el grupo el 2026-09-05: 763.409 proxies y 115.078.758 comprobaciones de verificación.
