ဤသည်မှာ [HProxy](https://hproxy.com/free-proxy-list) က ထုတ်ပြန်သော အခမဲ့ proxy စာရင်း ဖြစ်သည်။ engine တစ်ခုက မိနစ်အနည်းငယ်တိုင်း အများပြည်သူ ရင်းမြစ် ၁၀၀ ကျော်မှ ကိုယ်စားလှယ်လောင်းများကို ဆွဲယူပြီး တစ်ခုချင်းစီကို HTTP၊ HTTPS၊ SOCKS4 နှင့် SOCKS5 ဖြင့် စမ်းသပ်ကာ တုံ့ပြန်သော proxy တိုင်း၏ နိုင်ငံ၊ အမည်ဝှက်မှုအဆင့်၊ နှောင့်နှေးချိန်နှင့် uptime ကို မှတ်တမ်းတင်သည်။ ယခုအထိ proxy **774,098** ခုကို ခြေရာခံခဲ့သည်။ **6,318** ခုသည် ဤမိနစ်တွင် အသက်ဝင်နေပြီး **33,868** ခုသည် လွန်ခဲ့သော 48 နာရီအတွင်း တုံ့ပြန်ခဲ့ကာ အစုနှစ်စုလုံးကို ထုတ်ပြန်သည်- `live.txt` တွင် ယခု အလုပ်လုပ်နေသည်များသာ ပါဝင်ပြီး `all.txt` တွင် အခမဲ့ proxy များ ဝင်ထွက်နေသော ပိုကျယ်သော အစုအဝေး ပါဝင်သည်။ အကောင့်ဖွင့်ရန် မလို၊ API key မလို၊ ဖိုင်များကို လိုသလောက် ဆွဲယူနိုင်သည်။

repo နှင့် site တစ်ဒါဇင်မှ proxy များ စုဆောင်းနေပါက ဤစာရင်းတွင် ၎င်းတို့ ပါပြီးဖြစ်သည်။ တူညီသော အများပြည်သူ ရင်းမြစ်များမှ တည်ဆောက်ပြီး စစ်ဆေးထားသည်။ [ကျွန်ုပ်တို့ စုစည်းသော ရင်းမြစ်များ](#ကျွနုပတို-စုစညးသော-ရငးမြစများ) ကို ကြည့်ပါ။

## အတန်းတိုင်းက သင့်ကို ပြောပြသည့်အရာ

အခမဲ့ proxy စာရင်း အများစုက `ip:port` သက်သက်သာ ပေးသည်။ ဤနေရာတွင် အတန်းတိုင်းက proxy သည် request တစ်ခု လုပ်ထိုက်သလားဟု ဆုံးဖြတ်ပေးသော တိုင်းတာချက်များကိုပါ ဆောင်ထားသည်-

| အကွက် | အဓိပ္ပာယ် |
|-------|-------------------|
| `protocols` | HTTP၊ HTTPS၊ SOCKS4 နှင့် SOCKS5 အနက် အမှန်တကယ် တုံ့ပြန်ခဲ့သော protocol များ |
| `anonymity` | ပွင့်လင်း၊ အမည်ဝှက် သို့မဟုတ် elite- ပစ်မှတ်က သင့်၏ အစစ်အမှန် IP ကို မြင်နိုင်သလား |
| `country` / `city` | အထွက်နေရာ ဘယ်မှာရှိသလဲ |
| `latency_ms` | နောက်ဆုံး စစ်ဆေးမှုတွင် တိုင်းတာခဲ့သော တုံ့ပြန်ချိန် |

**ဤစာရင်းသည် အခြား အခမဲ့ proxy စာရင်းများနှင့် ဘယ်လို ကွာသလဲ။**
ဤနေရာရှိ proxy တိုင်းကို နေ့ရောညပါ ပြန်စစ်ဆေးပြီး ၎င်း၏ တိုင်းတာချက်များ ပါဝင်ကာ အခြားစာရင်းများ အသုံးပြုသော တူညီသည့် အများပြည်သူ ရင်းမြစ်များမှ တည်ဆောက်ထားသဖြင့် ဖိုင်တစ်ခုတည်းက စုစည်းမှုတစ်ခုလုံးကို အစားထိုးသည်။ နောက်ကွယ်ရှိ မှတ်တမ်းကိုလည်း ထုတ်ပြန်ထားသည်၊ [အခမဲ့ proxy များအကြောင်း ကိန်းဂဏန်းများက ပြောသည့်အရာ](#အခမဲ-proxy-များအကြောငး-ကိနးဂဏနးများက-ပြောသညအရာ) ကို ကြည့်ပါ။

## ကျွန်ုပ်တို့ စုစည်းသော ရင်းမြစ်များ

engine သည် အများပြည်သူ proxy ရင်းမြစ် ၁၀၀ ကျော်မှ ဆွဲယူ၊ ထပ်နေသည်များ ဖယ်ရှား၊ အားလုံးကို စမ်းသပ်ပြီး တိုင်းတာချက်များကို တစ်နေရာတည်းတွင် စုစည်းသည်။ အများပြည်သူ repo နှင့် proxy site တစ်ဒါဇင်ကို ကိုယ်တိုင် ဆွဲယူ၍ တိုက်ဆိုင်စစ်ဆေးမည့်အစား ၎င်းတို့၏ စစ်ဆေးပြီး ထပ်နေမှုကင်းသော ပေါင်းစည်းမှုကို နေ့ရောညပါ ဆန်းသစ်ထားသော အနေအထားဖြင့် ရရှိသည်။

ကျွန်ုပ်တို့ ဆွဲယူသင့်သော အများပြည်သူ proxy ရင်းမြစ် သိပါသလား။ [issue တစ်ခု ဖွင့်ပါ](https://github.com/hproxy-com/free-proxy-list/issues)၊ ထည့်သွင်းရန် စဉ်းစားပါမည်။

## အလုပ်လုပ်ပုံ

1. **စုစည်း**- မိနစ်အနည်းငယ်တိုင်း အများပြည်သူ ရင်းမြစ် ၁၀၀ ကျော်မှ ကိုယ်စားလှယ်လောင်းများ။

4. **ထုတ်ပြန်**- ရလဒ်ကို ဤနေရာတွင် တစ်နေ့လျှင် အကြိမ်များစွာ၊ [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list) တွင် မိနစ်အနည်းငယ်အတွင်း။
