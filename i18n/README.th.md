## แต่ละแถวบอกอะไรคุณ

รายการพร็อกซีฟรีส่วนใหญ่ให้แค่ `ip:port` เปล่า ๆ แต่ที่นี่ทุกแถวยังมีค่าที่วัดได้ซึ่งตัดสินว่าพร็อกซีนั้นคุ้มที่จะส่งคำขอหรือไม่:

| ฟิลด์ | ความหมาย |
|-------|-------------------|
| `protocols` | โปรโตคอลที่มันตอบกลับจริง จาก HTTP, HTTPS, SOCKS4 และ SOCKS5 |
| `anonymity` | โปร่งใส นิรนาม หรือ elite: ปลายทางเห็น IP จริงของคุณหรือไม่ |
| `country` / `city` | ตำแหน่งของจุดออก |
| `latency_ms` | เวลาตอบกลับที่วัดได้ในการตรวจสอบครั้งล่าสุด |
| `uptime_24h` / `uptime_7d` | ตอบกลับบ่อยแค่ไหน เพื่อให้พร็อกซีที่เคยใช้ได้ครั้งเดียวไม่ดูเหมือนพร็อกซีที่ใช้ได้ตลอด |

ทั้งหมดนี้อยู่ใน [all.json](../all.json) และ [all.csv](../all.csv) และใน[รายการสดที่ hproxy.com](https://hproxy.com/free-proxy-list) ซึ่งกรองทุกแถวได้ตามประเทศ โปรโตคอล ความนิรนาม และอัปไทม์

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",

หากต้องการกรองตามประเทศ โปรโตคอล และอัปไทม์โดยไม่ต้องโคลนอะไรเลย ให้ใช้ API แบบเรียลไทม์ฟรีที่มีเอกสารอยู่ที่ **[hproxy.com/docs/free-proxy-list](https://hproxy.com/docs/free-proxy-list)** หรือเปิด**[รายการสดที่ hproxy.com](https://hproxy.com/free-proxy-list)** ซึ่งพร็อกซีทุกตัวมีหน้าของตัวเอง

คุณนำรายการนี้ไปใส่ในซอฟต์แวร์ของคุณเองได้ฟรีโดยไม่ต้องขออนุญาต หากมีสิ่งใดใช้ไม่ได้ ฝ่ายสนับสนุนพร้อมให้บริการตลอด 24 ชั่วโมงที่ [hproxy.com/contact](https://hproxy.com/contact)

เอนจินเก็บประวัติของทุกพร็อกซีที่เคยเห็น ดังนั้นคำกล่าวอ้างทั่วไปเกี่ยวกับพร็อกซีฟรีจึงวัดได้แทนการเดา คิวรีแบบอ่านอย่างเดียวบนกลุ่มข้อมูลเมื่อ 2026-09-05: พร็อกซี 763,409 ตัว และการตรวจสอบยืนยัน 115,078,758 ครั้ง

- **พร็อกซีฟรีมีอายุประมาณหกวัน** ค่ามัธยฐานของอายุจากพร็อกซี 691,179 ตัวที่ตายไป: 144.5 ชั่วโมง 22.6 เปอร์เซ็นต์ตายภายในชั่วโมงแรก และ 17 เปอร์เซ็นต์อยู่ได้นานกว่าหนึ่งเดือน
- **พร็อกซีที่ใช้งานได้ตอบกลับไม่ถึงครึ่งของการตรวจสอบ** พร็อกซีในชุดที่ใช้งานได้ผ่านการตรวจสอบยืนยันของตัวเองเพียง 45.5 เปอร์เซ็นต์ จากพร็อกซี 765,494 ตัวที่เคยติดตาม (2026-09-06) มี 667 ตัวที่ตอบกลับการตรวจสอบตั้งแต่ 90 เปอร์เซ็นต์ขึ้นไป รายชื่ออยู่ที่ [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list)
- **รายการฟรีบนอินเทอร์เน็ตคือกลุ่มเดียวกัน** พร็อกซีที่ใช้งานได้โดยเฉลี่ยปรากฏใน 17.9 แหล่งจากที่เราดึง และ 94.7 เปอร์เซ็นต์ปรากฏในมากกว่าหนึ่งแหล่ง การคัดลอกจากหลายรายการให้พร็อกซีชุดเดิมที่มีแค่วันที่ต่างกัน

ในทางปฏิบัติ: ใช้พร็อกซีฟรีกับหน้าสาธารณะ การทดสอบ และการตรวจสอบตำแหน่ง โดยตั้ง timeout สั้น ๆ และลองใหม่ที่บรรทัดถัดไป งานใดที่มีการล็อกอิน การชำระเงิน หรือปลายทางที่ตรวจจับบอต ต้องใช้พร็อกซีที่ใช้งานได้ต่อเนื่องและไม่ได้แบ่งปันกับทั้งอินเทอร์เน็ต ดู [เมื่อพร็อกซีฟรีไม่พอ](#เมือพรอกซีฟรีไมพอ)

## คำถามที่พบบ่อย

**รายการนี้มีพร็อกซีฟรีกี่ตัว?**
ติดตามแล้ว 768,073 ตัว 4,088 ตัวใช้งานได้ในนาทีนี้ และ 60,837 ตัวตอบกลับใน 48 ชั่วโมงที่ผ่านมา และไฟล์ที่เผยแพร่มีจำนวนเท่านี้พอดี

**รองรับโปรโตคอลใดบ้าง?**
HTTP, HTTPS, SOCKS4 และ SOCKS5 ทุกพร็อกซีติดป้ายด้วยโปรโตคอลที่มันตอบกลับจริง ไม่ใช่โปรโตคอลที่ถูกลงรายการไว้

**รายการอัปเดตบ่อยแค่ไหน?**
ตัวเลือกถูกดึงจากแหล่งต่าง ๆ ทุกสองสามนาทีและทดสอบซ้ำตลอด 24 ชั่วโมง รีโปนี้รีเฟรชวันละหลายครั้ง และ[รายการสดที่ hproxy.com](https://hproxy.com/free-proxy-list) แสดงผลภายในไม่กี่นาที

**พร็อกซีเหล่านี้นิรนามหรือไม่?**
แต่ละตัวถูกจัดระดับเป็นโปร่งใส นิรนาม หรือ elite ตามว่าปลายทางเห็น IP จริงของคุณหรือไม่ กรองด้วยฟิลด์ `anonymity` ใน `all.json` หรือ `all.csv` หรือใช้ `elite.txt`

**ใช้พร็อกซีใน Python อย่างไร?**
ดู [ใช้ในโค้ดของคุณ](#ใชในโคดของคุณ) ด้านบน ดึง `all.txt` เลือกหนึ่งบรรทัด แล้วส่งให้ `requests` เป็นพร็อกซี `http` และ `https` ตั้ง timeout และไปบรรทัดถัดไปเมื่อล้มเหลว เพราะพร็อกซีฟรีตอบกลับไม่ถึงครึ่งของการตรวจสอบ

**ต้องใช้คีย์ API หรือบัญชีหรือไม่?**
ไม่ ทั้งไฟล์ดิบที่นี่และ [API ฟรีที่ hproxy.com](https://hproxy.com/docs/free-proxy-list) ไม่ต้องสมัครและไม่ต้องใช้คีย์

**ผู้ช่วย AI หรือเอเจนต์ใช้รายการนี้ได้หรือไม่?**
ได้ เซิร์ฟเวอร์ MCP, API ไม่ต้องใช้คีย์ และหน้า llms.txt สร้างขึ้นเพื่อสิ่งนี้ ดู [ใช้จากผู้ช่วย AI](#ใชจากผูชวย-ai)

**พร็อกซีฟรีปลอดภัยหรือไม่?**
ให้ถือว่าเป็นของสาธารณะและเชื่อถือไม่ได้ เหมาะกับการดึงหน้าสาธารณะ การทดสอบ และการตรวจสอบตำแหน่ง อย่าส่งรหัสผ่าน เซสชัน หรือข้อมูลการชำระเงินผ่านพร็อกซีสาธารณะเด็ดขาด: ผู้ที่ดูแลมันอ่านได้ทุกอย่างที่ไม่ได้เข้ารหัสแบบ end-to-end

**รายการนี้ต่างจากรายการพร็อกซีฟรีอื่นอย่างไร?**
ทุกพร็อกซีที่นี่ถูกทดสอบซ้ำตลอด 24 ชั่วโมงและมีค่าที่วัดได้ติดมาด้วย และรายการสร้างจากแหล่งสาธารณะเดียวกับที่รายการอื่นใช้ ไฟล์เดียวจึงแทนที่คอลเลกชันทั้งหมดได้ ประวัติเบื้องหลังก็เผยแพร่ด้วย ดู [ตัวเลขบอกอะไรเกี่ยวกับพร็อกซีฟรี](#ตัวเลขบอกอะไรเกียวกับพรอกซีฟรี)
