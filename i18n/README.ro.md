## Ce vă spune fiecare rând

Majoritatea listelor de proxy-uri gratuite vă dau un simplu `ip:port`. Aici fiecare rând poartă și măsurătorile care decid dacă proxy-ul merită o cerere:

| Câmp | Ce indică |
|-------|-------------------|
| `protocols` | Protocoalele pe care a răspuns cu adevărat, dintre HTTP, HTTPS, SOCKS4 și SOCKS5 |
| `anonymity` | Transparent, anonim sau elite: dacă ținta poate vedea IP-ul dumneavoastră real |
| `country` / `city` | Unde se află ieșirea |
| `latency_ms` | Timpul de răspuns măsurat la ultima verificare |
| `uptime_24h` / `uptime_7d` | Cât de des a răspuns, ca un proxy care a fost activ o singură dată să nu pară unul care rămâne activ |

Toate acestea se află în [all.json](../all.json) și [all.csv](../all.csv), precum și în [lista live de pe hproxy.com](https://hproxy.com/free-proxy-list), unde fiecare rând poate fi filtrat după țară, protocol, anonimat și disponibilitate.

Din cele 765.494 de proxy-uri urmărite vreodată (2026-09-06), 667 au răspuns la 90 la sută din verificări sau mai mult; sunt listate la [hproxy.com/free-proxy-list](https://hproxy.com/free-proxy-list).

Proxy-urile nu pot fi adăugate prin pull request: lista este regenerată de motorul de verificare la fiecare reîmprospătare, așa că o intrare commisă ar fi suprascrisă de următoarea. Contribuția utilă este [o sursă publică de proxy-uri](../CONTRIBUTING.md) din care motorul să poată aduna.

## Mențiuni legale

Aceste proxy-uri sunt agregate din surse disponibile public. Nu le căutăm prin scanare și nu stocăm nimic despre dispozitivele din spatele lor. Sunt oferite ca atare, fără garanție, doar pentru utilizare legală. Sunteți responsabil pentru felul în care le folosiți: respectați Politica de utilizare acceptabilă GitHub și legile locale și nu treceți niciodată parole sau date sensibile printr-un proxy public. Dacă o adresă IP vă aparține și doriți să fie eliminată, deschideți un issue.
