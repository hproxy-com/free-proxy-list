## What each row tells you

Most free proxy lists hand you a bare `ip:port`. Each row here also carries the measurements that decide whether the proxy is worth a request:

| Field | What it tells you |
|-------|-------------------|
| `protocols` | The protocols it actually answered on, out of HTTP, HTTPS, SOCKS4 and SOCKS5 |
| `anonymity` | Transparent, anonymous or elite: whether the target can see your real IP |
| `country` / `city` | Where the exit sits |
| `latency_ms` | Measured response time on the last check |
| `uptime_24h` / `uptime_7d` | How often it answered, so a proxy that was up once does not look like one that stays up |

All of it is in [all.json](all.json) and [all.csv](all.csv), and on the [live list at hproxy.com](https://hproxy.com/free-proxy-list), where every row can be filtered by country, protocol, anonymity and uptime.

## Use it in your code

**Python (requests):**

```python
import random, requests

proxies = requests.get(
    "https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt"
).text.split()

proxy = random.choice(proxies)
r = requests.get("https://api.ipify.org",
                 proxies={"http": f"http://{proxy}", "https": f"http://{proxy}"},
                 timeout=10)
print(r.text)
```

**curl:**

```bash
curl -x http://$(curl -s https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/http.txt | head -1) https://api.ipify.org
```

**Node.js:**

```js
const list = await fetch("https://raw.githubusercontent.com/hproxy-com/free-proxy-list/main/all.txt")
  .then(r => r.text());
const proxies = list.trim().split("\n");
```

In practice: use free proxies for public pages, tests and location checks, with a short timeout and a retry on the next line. ## FAQ

**How many free proxies are in this list?**
767,879 have been tracked so far. 4,321 are live at this minute and 61,224 answered within the last 48 hours, and the published files hold exactly those.

**Which protocols are supported?**
HTTP, HTTPS, SOCKS4 and SOCKS5. Each proxy is labelled with the protocols it actually answered on, not the ones it was listed under.

**How often is the list updated?**
Candidates are pulled from the sources every few minutes and re-tested around the clock. This repository is refreshed several times a day, and the [live list on hproxy.com](https://hproxy.com/free-proxy-list) shows results within minutes.

**Are the proxies anonymous?**
Each one is graded transparent, anonymous or elite by whether the target sees your real IP. Filter on the `anonymity` field in `all.json` or `all.csv`, or take `elite.txt`.

**How do I use a proxy in Python?**
See [Use it in your code](#use-it-in-your-code) above. Pull `all.txt`, pick a line, and pass it to `requests` as the `http` and `https` proxy. Set a timeout and move to the next line on failure, because a free proxy answers fewer than half of its checks.

**Do I need an API key or an account?**
No. The raw files here and the [free API on hproxy.com](https://hproxy.com/docs/free-proxy-list) need no signup and no key.

**Can an AI assistant or agent use this list?**
Yes. The MCP server, the keyless API and the llms.txt pages are made for that; see [Use it from an AI assistant](#use-it-from-an-ai-assistant).

**Are free proxies safe to use?**
Treat them as public and untrusted. They are fine for scraping public pages, testing and location checks. Never send passwords, sessions or payment data through a public proxy: whoever runs it can read anything that is not encrypted end to end.

**How is this list different from other free proxy lists?**
Every proxy here is re-tested around the clock and carries its measurements, and the list is built from the same public sources the other lists use, so one file replaces the collection. The history behind it is published too, see [What the numbers say about free proxies](#what-the-numbers-say-about-free-proxies).
